# AI造梦机

AI造梦机是一款面向个人创作者和小型内容团队的 AI 视频创作平台，帮助用户将创意或故事，通过可编辑、可确认的制作流程，转化为故事短视频或漫剧视频。

两条主链路独立，共用账号、知识库、素材、任务版本与作品库；另保留文艺短视频、角色动作短片、图片配音口播三种快捷工具。

## 启动

管理员在本项目 `.env` 用 `ADMIN_USER_IDS` 配置（user_id以逗号分隔，默认无管理员），修改后重启后端。当前本机登录账号已配置为管理员；其他邀请码账号不会自动获得此权限。`/api/auth/me` 的 `is_admin` 是后端计算结果，前端字段不作为权限凭证。

可选模型由 `.env.example` 中的 `PUBLIC_*_MODELS` 名单和协议能力表共同限制，修改后重启后端。普通用户通过 `/api/models` 获取安全目录；若某组被设为空或旧选择已下线，界面会提示重新选择，不静默回退。运行中的项目暂时不能修改模型。

生成额度配置为 `MAX_ACTIVE_EXECUTIONS=2`、`MAX_ACTIVE_EXECUTIONS_PER_USER=1`、`MONTHLY_BUDGET_CNY=500`、`MONTHLY_USER_BUDGET_CNY=100`。价格从 `backend/model-cost-rates.json` 读取，或以 `MODEL_COST_RATES_JSON` 覆盖；缺少可核对价格的模型拒绝收费调用。按北京时间自然月控制预算，先预留再按用量/价格表计算，供应商实际费用未知时为 `null`，不能当作实付0元。详见[配置与口径](docs/使用与运维说明.md)。

V1.3 漫剧渲染需要本机 FFmpeg / ffprobe、Pillow 与可用中文字体。macOS 默认使用系统中文字体；其他环境可设置 `COMIC_FONT_PATH` 为支持中文的字体文件绝对路径。字幕采用透明图片烧录，不依赖 FFmpeg 的 libass。配音为在线 Edge TTS，需要网络；画面运镜与合成本地执行。

漫剧入口：登录后在创作首页选择「漫剧创作」。每个阶段生成后可检查、修改和确认；创建后不可将该项目原地切换为故事短视频。第一版为单集、基础平移/推近与字幕，不包含精准口型、声音克隆或自由时间线编辑。修改对白/声线后请按失效提示更新配音与成片，历史版本仍可查看。

V1.2 增加 FastEmbed、Qdrant client 与 pypdf，按 `backend/requirements.txt` 安装。首次知识资料上传会下载中文模型（本机已预热）；后续本地缓存运行，不产生检索 API 费用。**后端仅用一个 worker**，知识数据、向量和模型位于 `data/knowledge/`。详见 [RAG 技术与数据设计](docs/RAG/RAG技术与数据设计.md)。生成时资料发送范围在前端选择器告知。

## 版本与任务恢复

- 草稿按账号保存到浏览器 localStorage。已上传文件的引用可恢复；未上传文件需重新选择，上传目录中的文件不存在时需重新上传。
- 主流程阶段生成完成后等待确认，刷新不会自动执行下一阶段。执行状态来自后端；SSE 断开只停止前端跟踪，不取消后台生成。
- 编辑保存不调用模型；「重新生成」才提交新执行。更换上游内容或素材后，原下游产物保留为历史，并标为待更新。
- 阶段版本选择保留该版本的真实输入关系；与当前上游不一致的旧版本仍是待更新状态，不能通过选旧版把当前成片变为有效。
- 当前成片仅在依赖有效时可导出。「下载历史成片」可独立下载已登记版本，不需要把它恢复成当前版本；API 使用 `GET /api/sessions/{id}/export?version_id={版本ID}`。
- 故事执行与快捷任务均支持 `Idempotency-Key`。同一次请求在网络重发时使用同一个标识；用户明确发起新的生成使用新标识，避免重复提交。
- 「继续未完成」通过独立 `/recovery`、`/resume` 接口处理原执行。输入快照包含原模型、参数、上游版本/文件及适用知识版本；变化后拒绝续接，旧任务没有快照时也不伪造恢复。已受理图像/视频任务查询/下载；未提交或明确HTTP未受理的`rejected`步骤在用户继续后创建新attempt并预留，复用其他成功产物。`unknown`、408/409/5xx等结果不明时提示核对，不提供盲重提按钮。
- 普通「重新生成」使用当前输入新建执行，可能产生新费用，不能与供应商任务续接混淆。配音不具备供应商任务续传，详见[恢复范围](docs/使用与运维说明.md)。
- 生成图片的素材列表、媒体读取与复用复制均校验账号归属和文件边界。素材复用仍受原有上传用途限制，页面提示模型去向与用途。

## 边界与已知问题

- 内容红线：禁止生成真人肖像、侵权 IP、违法内容（提示词 + 结果双向拦截）。
- 模型网关：AIHubMix，文本 qwen3.5-plus / 图片 qwen-image-2.0 / 视频 wan2.7-i2v·r2v。
- 角色动作短片只需人物图与动作描述，不再强制上传未被模型使用的动作视频；仍不提供参考视频的像素级动作迁移。
- 图片配音口播可选「人物嘴型同步」或「静态图片配音」。嘴型模式采用wan2.6-i2v原生生成声音与人物口型，生成10秒720p素材，自动裁去持续静音尾段，成片可能短于10秒；最多40个非空白字符，音色由模型生成；按现有价格表约¥7.232/次，裁尾不减少已生成素材的费用。静态模式沿用Edge TTS，不动嘴。新草稿默认嘴型，旧草稿和历史任务缺字段时仍按静态处理；失败不会回退为静态成功，效果验收见项目状态。
- 真实生成速度受模型商延迟影响，视频片段约 1~2 分钟/段。
- 并发分镜优化已暂缓。
- 首页视觉图片与电影参考用于展示创作氛围，灵感卡点击只填入创意；正式作品库读取本人会话与短任务。验收记录中的替身截图仅演示四类作品混排，不代表实际生成成果。3D 为 WebGL 门框、图像平面与光点，减少动态时停止动画，WebGL 不可用时回到静帧。
- 供应商任务续接和预算控制已接入，当前仍为单worker、SQLite及本地Qdrant架构，不等于分布式队列、多实例部署或供应商账单系统。未知提交需核对，预算是按表控制额度，不保证与供应商最终账单完全相同。
- 本轮故事、漫剧各1人1场景1集2镜头，均`session_completed`且播放到`ended`无错误。故事10.099秒、1280×720；漫剧3.755秒、720×1280，含2句中文字幕及Edge TTS。灯塔尺度/人物合成感、漫画背景与线稿风格、信封颜色跨镜头仍有偏差，语音自然度未做人工听审；AC07/COMIC07不据此宣布全优，RAG08另验。详情见[本轮证据](docs/evidence/真实样片验收/验收记录.md)。
