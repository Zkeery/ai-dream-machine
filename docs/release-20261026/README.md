# 本轮 Mock 收口

三条已有人工复核已按当前 v13 检查结果关联：R07、H01、R10 的问题、完整资料版本、保存回答、完成版本及请求/响应文件哈希均与原评审材料一致，仅机器注释改变。没有重新评分，9 项原判断及理由保留在 `review-version-links.json`。R10 仅适用于原交通画面创作请求，不扩展成普遍的世界存在性规则。H05 机器提示保持 NEED_REVIEW。

产品的内容检查仅在 Mock 模式接入剧本、分镜和漫剧分镜，沿用冻结检查器。发现的问题会标明所在步骤和文字，给出修改建议；未发现提示不等于验收通过。检查不评判视频画面、声音或完整语义，也不会把历史人评迁移给新生成内容。

检查记录随作品持久化；生成、保存修改会检查，切回旧版本会显示对应记录。检查故障时保留内容，支持重新检查。已有阶段确认、局部重生成、历史版本、失败恢复继续保留。

`verify_release_review_links.py` 为本地历史核验工具，需要原始证据目录；发布的关联清单包含全部绑定摘要和原判断。历史大体积原材料仍留本地，不作为产品运行依赖。

验证结果见 [validation.md](validation.md)，演示点击顺序见 [demo-route.md](demo-route.md)。第 2、3、4 项扩展及真实模型、云端复验、生产部署均暂停，本次只交付 Mock 下的关联和产品接入。
