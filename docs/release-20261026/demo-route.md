# 两分钟 Mock 演示路线

本路线只演示本地产品流程。内容检查示例、故障和媒体均为固定离线素材，不代表真实模型质量；无模型调用或计费。

## 演示前准备（不计入两分钟）

按根目录 README 启动隔离演示服务，打开 http://127.0.0.1:3030 ，邀请码为 `DEM23456`。数据保存到 `.runtime/release-demo/data`，不会改动正式作品。

1. 创作台选择“故事短视频”，输入“内容检查演示：访客只能在展示区活动，不能进入设备间。”，创建并生成剧本。演示服务会故意在剧情里放入一条无依据的安全保证，便于展示自动检查。
2. 点击“确认剧本，进入角色场景”，生成角色和场景图；再返回“剧本”页签。保持作品未归档，便于演示修改和局部重生成。
3. 再建一个作品，输入“恢复演示：小林在雨夜找到一只猫。”，点击“生成剧本”。演示服务启动后的第一次此类请求会模拟中断；保留失败状态，先不要点击继续。如果已演示过恢复，可重启演示服务后重建这条作品；旧作品会保留。

## 按顺序点击

| 时间 | 页面与点击 | 展示什么 |
| --- | --- | --- |
| 0:00–0:25 | 创作台／我的作品 → 打开“内容检查示例” → “剧本” | 生成完成后自动出现“内容检查”：指出剧情里的安全保证、所在步骤、原句及建议改法。说明未显示内部用例编号。 |
| 0:25–0:45 | “编辑内容” → 将剧情改为“访客只能在展示区活动，不能进入设备间。” → “保存修改” → “查看检查历史” | 保存即重新检查；新旧检查都保留。“未发现规则能识别的问题”不等于人工验收通过。 |
| 0:45–1:00 | “阶段版本” → 选回版本 1 | 恢复原剧本，展示与旧内容对应的检查提示；修改记录仍在检查历史中。 |
| 1:00–1:15 | “确认剧本，进入角色场景” | 用户确认后才进入下一阶段；展示已有角色与场景资产。 |
| 1:15–1:35 | 角色图下“修改提示词 / 重新生成” → 增加“戴一条围巾” → “重新生成这张图” | 只刷新所选角色图，场景图保持原样；这是局部重生成。Mock 图片是占位素材，演示的是操作范围。 |
| 1:35–2:00 | “我的作品” → 打开“恢复演示…” → “继续未完成阶段” | 从保留的输入恢复，回到“等待确认”；展示错误消失、剧本和检查结果出现，不需要从头重建。 |

成片页可作为附加展示：已完成作品 → “预览成片”。本轮已实测生成、播放和归档；两分钟主线重点展示上表五项能力。
