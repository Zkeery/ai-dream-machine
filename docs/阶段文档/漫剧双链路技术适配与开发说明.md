# 漫剧双链路技术适配与开发说明

日期：2026-10-04。需求依据：PRD V1.3 第12节与用户确认的两条独立主链路。

## 产品形态与范围

AI造梦机是一款面向个人创作者和小型内容团队的AI视频创作平台，帮助用户将创意或故事，通过可编辑、可确认的制作流程，转化为故事短视频或漫剧视频。

在同一个 AI造梦机应用内增加漫剧视频工作流。采用确定性阶段编排，各阶段由用户触发并确认；不新增自主 Agent Loop，不拆分部署服务。沿用 FastAPI、SQLite、Next.js 和已有模型客户端。当前 AI 按现有代码与手册分析，未运行蓝图模型管线。

首页并列故事短视频与漫剧；故事新建默认 1 集，主动修改后按选择提交，已有作品不改写。漫剧首期固定单集、默认竖屏。以剧本、角色设定、分镜对白、漫画镜头图、角色配音、运镜字幕成片完成最小闭环。条漫排版、翻页阅读、复杂动画动作、口型、声音克隆和自由时间线编辑暂缓。

## 系统与数据边界

| 事项 | 方案 |
| --- | --- |
| 项目身份 | `SessionCreate` / `SessionMeta.project_type` 为 `story` 或 `comic`；缺省 `story`，创建后不提供切换接口 |
| 旧数据兼容 | 本次双链路迁移增加带默认值的 `project_type` 文本列；后续模型选择迁移另增 `model_selection` JSON 列。启动幂等补列，旧产物和版本不改写 |
| 故事工作流 | 保留已有六阶段、产物结构与导出行为 |
| 漫剧工作流 | 单独定义阶段、产物校验、依赖、失效与最终 MP4 导出，不用漫画名称包装旧视频阶段 |
| 可共用部分 | 账号归属、知识库与检索快照、角色参考图、受保护媒体访问、SQLite任务执行和版本记录 |
| 前端 | 两条流程独立草稿；会话决定当前流程，作品库标明类型；沿用夜幕影院视觉 |

暂不引入新模型厂商或云资源。模型预算沿用每月 500 元；开发期替身测试不花模型费用，真实生成费用与效果单独记录。

## 媒体合成

漫画分镜保存稳定镜头 ID、角色与场景引用、逐句台词、说话人和基础运镜。先获取每句真实音频时长，推导字幕起止和镜头持续时间；然后本地 FFmpeg 合成镜头并拼接整集。无台词镜头采用明确停留时长。

当前机器的 FFmpeg 不包含 `libass/subtitles/drawtext`。兼容实现使用现有 Pillow 与中文字体生成透明字幕图，按实际时间通过 `overlay` 烧录，同时保留 SRT。台词文本不直接拼接进 FFmpeg 表达式。字体缺失需明确错误；长字幕换行并保持安全边距。

配音使用既有在线 Edge TTS，固定角色声线，不把修改音高等同于情绪表演。基础平移/缩放由 FFmpeg 执行；首期不宣称人物肢体动作或口型能力。

## 修改与恢复原则

- 台词或声线改变应影响对应配音和最终成片；角色参考图不因此重新生成，画面输入未变时保留可复用镜头图。
- 分镜画面、角色引用或所选图片改变时，受影响的镜头与成片必须明确失效。
- 历史版本继续可查看；生成与下载使用当前有效输入，旧成片不能被当作最新成片。
- 模型输出强校验，生成失败进入持久终态，错误可读；SSE结束后前端仍可刷新恢复状态。
- 所有读取、执行、媒体与导出延续后端 owner 校验。客户端不能通过自行传入项目类型绕过阶段边界。

## 验证策略与当前限制

1. 替身模型验证两套阶段隔离、产物合同、局部修改与失效、任务恢复、账号隔离和旧故事回归。
2. 真实本地 FFmpeg 验证中文烧录、音画时长、输出比例和可解码性；测试素材和生产生成分开标注。
3. 前端类型检查、Lint、测试、构建；浏览器检查桌面和移动宽度的双入口、编辑、试听和导出。
4. 真实模型样片按 PRD COMIC07 和既有 D7 标准人工验收。替身和本地测试片不能替代人物一致性、叙事和配音自然度验收。

实施与验证结果在 [漫剧验收记录](../evidence/漫剧/验收记录.md) 更新。原 RAG 留出集失败及 AC07 待验状态保持原样。

## 实际入口与运行验收

- 创建页面：故事 `/`；漫剧 `/?project=comic`。项目 URL 的类型提示以服务器 `project_type` 为准。
- 会话接口沿用 `/api/sessions`；漫剧新增 `/api/comic/voices` 返回受支持声线。阶段顺序由项目类型确定，越界阶段请求失败。
- 漫剧专有产物：`comic_storyboard`、`comic_panels`、`comic_audio`、`comic_composition`。音频与视频等可访问产物置于会话的受保护媒体目录。
- 根数据库和 `SessionStore` 增加 `project_type`；资产库原有泛型登记可直接复用漫画镜头图，增加了实际API复用/归属回归。
- 最终成片生成后点击“确认完成并归档”，调用原 `continue` 接口，按服务端 `session_completed` 更新；旧故事也补上相同确认入口。
- `backend/scripts/serve_comic_acceptance.py` 提供强制隔离的零付费测试后端；前端 standalone脚本支持 `PORT` 环境变量，缺省仍为3030。验收临时端口不是新的产品部署配置。

漫剧首轮交付时离线回归186项、前端31项，类型/Lint/build通过；真实本地FFmpeg及浏览器全流程、局部更新、下载和重启恢复通过。后续模型选择增量的最近回归为后端240项、前端54项，见[模型选择验收](../evidence/用户模型选择/验收记录.md)。这些工程结果没有替代最新真实模型从创意到成片、在线TTS效果、人物一致性和叙事质量验收；COMIC07仍待验。

## 创作入口与作品删除补充（2026-10-04）

用户验收提出：移除顶部重复的创建按钮，三种快捷工具明确归属短视频，允许清理误建的故事/漫剧作品。沿用现有 Next.js、FastAPI、SQLite，无新服务或费用。

- 「创作台」返回当前类型的创建表单；提交表单才创建作品。漫剧首页隐藏三种短视频快捷卡片，顶部「短视频工具」仍可进入。知识库页面明确双链路共用、项目各自绑定。
- `DELETE /api/sessions/{session_id}`：当前账号的非运行作品删除成功返回204；不存在、已删除或不属于本人返回404；正在生成返回409和可读提示。
- `session_deletions` 保存逻辑删除记录，会话读取、列表、保存和任务领取检查该记录，避免旧快照或重复请求恢复已删作品。删除与运行任务检查使用SQLite事务。
- 作品卡片确认后发起删除，显示提交/失败状态；成功清除列表和预览，删除当前项目返回作品库。知识库、共享素材和实际媒体文件不物理清理，快捷任务不在此次删除范围内。
- 验证覆盖取消、成功、失败、重复点击、权限隔离、运行状态、读取/导出屏蔽与刷新持久性；不需要调用模型。

## 权限、模型与首页展示补充（2026-10-04）

- 工作室设置与沙盒仅管理员可访问；普通用户可在创作时选择公开生成模型。漫剧显示文字/图片，声音仍用独立角色声线，本地合成不展示视频大模型选项。
- 模型偏好由创建请求或 `PATCH /api/sessions/{id}/models` 持久化；运行中拒绝修改。修改偏好只影响后续生成，历史产物保留实际模型；选择历史素材时恢复对应来源，未知旧来源不伪造。
- 首页不显示“单集漫剧…第一版无口型同步”技术说明，但本开发说明仍保留实际能力边界。右侧两张悬浮卡片采用雨夜女孩和云上城市两张不同图片；下方电影灵感参考区保持不变。页面展示调整不改变工作流阶段或生成合同。
