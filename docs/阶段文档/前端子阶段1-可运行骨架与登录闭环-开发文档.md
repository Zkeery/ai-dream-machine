# 前端子阶段 1 开发文档：可运行骨架与登录闭环

> 配套：前端技术适配声明、后端接口（已就绪）、PRD V1.0。

## 1. 本阶段目标
用户打开页面后，能用邀请码登录、进入工作台、看到"我的会话"（空或真实列表）、可退出登录。工程骨架与设计系统就位，为后续创作闭环打底。

## 2. 范围
### 本阶段包含
- Next.js（App Router + TS strict + Tailwind）工程骨架
- 设计变量（深色中性方案，语义 token）
- 登录页（邀请码登录、错误提示、加载/禁用态）
- 工作台布局（顶栏 + 左侧导航/列表 + 主内容区）
- 集中式 API 客户端 + 鉴权（Bearer token 存 localStorage）
- 「我的会话」列表（真实接口，含空/加载/失败态）
- 退出登录

### 本阶段不包含
- 6 阶段生成流程、短管线、任务中心（后续子阶段）
- 响应式精调（骨架先保证桌面可用，后续统一查）
- 视觉定稿（先用中性深色，待产品反馈）

## 3. 用户流程
1. 打开 http://127.0.0.1:3030 → 未登录 → 登录页
2. 输入邀请码 → 登录 → 进入工作台，右上角显示用户标识
3. 左侧看到「我的会话」列表（有数据显示片名，无数据显示空态）
4. 点「退出」→ 回到登录页，本地状态清空

## 4. 页面状态矩阵
| 页面/模块 | 初始 | 加载 | 空 | 失败 | 成功 |
|---|---|---|---|---|---|
| 登录页 | 输入框+按钮 | 按钮禁用+加载中 | — | 显示错误（码无效） | 跳转工作台 |
| 工作台 | 布局 | 会话列表加载中 | 空态"暂无会话" | 显示重试 | 会话列表 |

## 5. 接口契约
- POST /api/auth/login（{invite_code} → {token,user_id,expires_at}；403 邀请码无效/作废）
- GET /api/auth/me（Bearer → {user_id,invite_code,created_at}；401 未登录）
- POST /api/auth/logout（吊销 token）
- GET /api/sessions（Bearer → 会话数组，按 updated_at 倒序）
- GET /api/health

## 6. 实现方案
- 路由：`/login`（登录页）、`/`（工作台，未登录重定向 /login）
- 组件：`components/ui/Button`、`Input`；`components/layout/` 顶栏；`features/auth`、`features/sessions`
- 状态：token 存 localStorage，React Context 维护登录态
- API：`lib/api/client.ts` 统一 base、鉴权头、错误归一化（后端错误结构 `{error:{code,message}}`）
- 代理：next.config `rewrites` 把 `/api/*` 转发到 `http://127.0.0.1:8030/api/*`
- 安全：密钥不进前端；token 仅 localStorage（已在适配声明说明偏离）

## 7. 验收标准
- 未登录访问 `/` 重定向登录页
- 有效邀请码登录成功进入工作台；无效码显示可读错误
- 会话列表真实拉取后端；空态/加载态/失败态正确区分
- 退出后回登录页，会话列表与输入清空（修复过的最小界面 bug 不回归）
- 自动检查：lint / typecheck / test / build 全过
- 浏览器真实验证：桌面 + 移动端可登录、列表可看

## 8. 风险与回退
- 风险：Next.js 版本与 Node 24 兼容；rewrites 代理配置错误
- 回退：若 Next 脚手架异常，回退到 Vite + React 手动搭（但会偏离手册默认栈）
