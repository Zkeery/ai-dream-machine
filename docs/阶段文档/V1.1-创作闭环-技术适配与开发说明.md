# PRD V1.1 · 创作闭环技术适配与开发说明

> 2026-10-03；需求入口：[PRD V1.1](../PRD/PRD.md)。用户明确要求实际开发；本文记录已接入源码的合同和验证。代码与离线集成验收完成，新增模型视觉效果待验。

## 范围与已有实现

保留「夜幕影院 3D」视觉、两个本地进程、现有会话 / 任务标识、SQLite 与产物文件、账号归属和原模型供应商。通过统一产品视图兼容故事会话与快捷任务，不删除历史数据，不引入新的部署服务。

本轮覆盖 PRD 三个批次：草稿 / 参数 / 任务可靠性，故事素材 / 版本，统一作品库 / 素材复用 / 导航。完整动作迁移、嘴型同步、剧本续写及完整故事后期配音字幕继续作为后续目标。

## 实现合同

### 前端

- 草稿以当前账号隔离，保存文本、适用参数、工具与已上传素材引用；未上传文件不伪装成已恢复。
- 页面地址表达工作区、故事、工具与快捷任务；刷新与前进后退恢复上下文。
- 作品库合并现有故事与快捷任务，保留来源、状态、结果和继续入口。
- 生成进度读取后端事实并可恢复订阅 / 轮询；失败保留输入，重试由用户触发。
- 故事编辑、选版和待更新状态使用后端版本字段，不能静默显示旧结果为最新。

### 后端任务

- 保持原会话和任务 API，故事启动仍返回 `progress / done / error` SSE；新增只订阅的会话 stream。
- 同一后端进程持有执行任务，SSE 断开不会取消生成。SQLite 保存执行状态与事件，连接各自读取事件，不互相消费。
- 活跃任务重复启动复用执行；不同阶段冲突返回明确错误。快捷任务支持幂等提交。
- 重启不重新提交模型；无法确定恢复的执行明确标为中断 / 失败，保留输入和产物。

### 素材与版本

- 兼容 `artifacts`，增加阶段历史、选定版本、下游失效标记与执行输入记录，并在 SQLite 中保存。
- `intervene` 支持保存、重新生成与选择版本。保存 / 选版不调用模型；修改内容真实进入下一次输入。
- 角色 / 场景图片进入参考图或对应视频请求。使用厂商正式支持的字段，能力不支持时明确失败，不能仅把描述当作参考图。
- 下游失效保留历史产物；最新导出与后期拒绝混用无效版本。

### 素材列表与复用 API

- `GET /api/assets`：列出当前账号元数据中登记、真实存在的生成图片。
- 返回 `asset_id / source_type / source_id / source_title / stage / kind / name / url / updated_at / stale / version_id`。
- `GET /api/assets/{asset_id}/media`：鉴权读取同一素材。
- `POST /api/assets/reuse {asset_id}`：复核归属与路径，将明确选定的素材登记成现有上传输入；返回 `filename / original_name / file_path / asset`。
- 任务使用安全 `filename` 与 `asset_source` 来源记录，继续走既有上传归属校验。客户端不能指定任意本地路径。

## 实施与验证顺序

1. 前后端分别实现稳定状态、草稿和任务恢复，保留接口兼容。
2. 接通版本合同、真实图片参考输入与素材复用，再串起统一作品库。
3. 临时数据库和模型替身验证任务重连、多订阅、幂等、重启、引用和权限；实际重启隔离进程验证持久状态。
4. 完成 typecheck、lint、前端测试、后端测试与生产构建，再浏览器验证实际页面和不同宽度。
5. 更新证据、PRD 差距、架构图与项目状态；真实模型效果单独标记，不能用隔离结果冒充。

## 验收记录

最终后端全量 120 项、前端 16 项测试通过；typecheck / lint / build 通过。测试使用临时数据、模型与 HTTP 替身，覆盖持久执行、断流、多订阅、幂等、两个独立进程实际重启、素材权限、保存 / 重生成、版本来源和失效导出；角色提示词、指定镜头范围、未受影响镜头复用、局部失败保留，以及剩余失效的精准终态恢复已补齐。

局部重生成合同：`intervene.modifications` 使用 `operation: regenerate`、`target_ids`（角色 / 场景 item ID，参考 / 视频 shot ID）、按 ID 的 `prompts`，角色 / 场景另支持 `descriptions`。每项实际 `input_dependencies` 与版本绑定存入 artifact JSON；`stale_items` 标记剩余失效条目。只重做选定项，保留其他文件；尚有失效条目时阶段不能确认或默认导出。未受影响的镜头继续有效复用。执行 ledger 用精确 `parent_execution_id` 关联外围执行，局部完成而阶段仍待更新也能正确恢复 done。

集成审查修复三处实际问题：快捷任务原上传绝对路径恢复为安全文件名再校验归属；完成故事重生成走 intervene；历史产物选回后保留其原输入版本，与当前上游不一致则仍待更新，不能默认导出旧成片冒充最新。

浏览器检查包含实际草稿持久、首页参数带入工具、控制失败后保留输入、URL 恢复，以及 390 / 768 / 1280 / 1440 宽度。空账号的四类型作品展示与素材交互使用页面内受控响应，未向用户数据库写入假作品。具体 AC 与验证边界见[验收记录](../evidence/V1.1创作闭环/验收记录.md)。
