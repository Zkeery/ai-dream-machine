# 夜幕影院 3D 首页 · 前端适配与开发说明

初版：2026-10-03。当前范围核对：2026-10-04。

## 当前首页（V1.3）

首页按故事短视频/漫剧视频切换独立草稿，故事默认1集、漫剧固定单集。顶部为创作台、我的作品、短视频工具、知识库；取消重复新建按钮，设置/沙盒由管理员权限控制。模型选择面向普通用户，按流程能力展示并保存至项目，细节见[模型选择技术说明](用户模型选择技术适配.md)。

右侧两张悬浮卡片为不同概念图：左雨夜女孩、右云上城市；点击分别填入人物/场景灵感。下方三张真实电影参考与出处保留，表单下方漫剧技术说明已移除。四导航提供悬停、键盘焦点与44px触控，减少动态时关闭位移。当前素材见[来源说明](夜幕影院3D-素材说明.md)，页面证据见[管理员与首页验收](../evidence/管理员与导航视觉/验收记录.md)。以下章节保留初版接入记录，其四入口、新建和管理导航描述只适用于当时版本。

## 已确认的视觉方向与范围

用户选择 V04「夜幕影院」的排版，并认可 V05 的 3D 细化版本。此次将该视觉接入本项目的正式本地首页：大幅电影场景、左侧标题与创作输入、右侧人物与分镜卡、下方故事灵感与真实作品入口。

沿用 Next.js 16、React 19、TypeScript strict、Tailwind 4 和现有 API。3D 使用原生 WebGL，不新增渲染依赖。原型中的画面来自内置 image_gen 的原创静帧；其生成提示词另记录在本项目的素材说明。

## 页面与组件

- 顶部导航承接创作台、我的作品、短视频工具、设置、沙盒、退出与新建。
- 首页四种创作入口：故事成片调用现有 createSession；其他入口打开现有 PipelinesPanel 的对应标签。
- 灵感卡片填入创意，用户点开始造梦后才创建作品。风格、剧集数与比例保留为创作设置。
- 已有作品以真实 listSessions 结果展示，区分加载、空数据与失败；打开后沿用 CreationPanel 和 session URL 恢复。
- WebGL 场景组件使用独立资源生命周期：挂载初始化，卸载释放；减少动态、暂停、页面隐藏和离屏时停止持续绘制；上下文丢失显示静帧。
- 采用 V05 已确认的深色、薄荷色与电影层级，统一现有按钮、表单和内容面板的语义颜色。

## 接口与数据边界

createSession 的 idea、style、episodes、video_ratio 字段保持原契约。六阶段生成与确认、短管线提交、认证、权限隔离、下载、设置和健康接口沿用原实现。

装饰性电影静帧与人物卡为灵感示例，不能显示成用户已生成的作品。首页浏览、填入示例、切换场景和视觉验证不会调用收费模型。真实模型生成仍由用户点击现有生成按钮触发。

## 验证与交付

执行前端类型检查、Lint、生产构建；针对三维投影的视口与层级对齐添加小型自动检查。浏览器核对四个验收宽度 390/768/1280/1440，并验证模式入口、新建、真实列表、设置、沙盒、3D 视差、暂停、减少动态与静帧降级。

证据与范围结论记录在 docs/evidence/夜幕影院3D/验收记录.md；更新 README 和 docs/项目状态.md。本次保持本地自用运行方式：前端 3030、后端 8030。
