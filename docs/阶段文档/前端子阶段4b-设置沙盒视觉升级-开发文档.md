# 前端子阶段 4b 开发文档：设置页 + 沙盒页 + 视觉升级

> 配套：前端技术适配声明、子阶段 1~4 文档、参考项目 xiaoyunque。

## 1. 目标
补齐参考项目有而我们缺的「设置页」「沙盒页」，并把前端整体视觉从"毛坯"升级到"清爽可用"。

## 2. 范围
### 包含
- 左侧导航侧栏（创作 / 短管线 / 设置 / 沙盒），带图标（Lucide）
- 设置页：展示当前模型配置（LLM/VLM/图像/视频/网关）、内容安全开关状态
- 沙盒页：项目状态 + 后端健康 + 任务统计（简单演示/调试页）
- 视觉升级：导航、卡片、按钮、登录页、阶段进度步骤条、留白与排版
- 后端新增 `GET /api/settings`（只读配置信息）

### 不包含
- 设置页编辑/保存密钥（密钥仍走 .env，避免前端存密钥）
- 沙盒页的真实 workflow 编排调试（只做状态展示）

## 3. 用户流程
登录 → 左侧导航切换 创作 / 短管线 / 设置 / 沙盒；设置页看到当前模型与安全开关；沙盒页看到服务状态。

## 4. 实现要点
- 导航：`features/workspace/` 内加侧栏；视图切换用状态或 URL
- 图标：lucide-react（Video、Zap、Settings、FlaskConical、LogOut 等）
- 设置：`features/settings/SettingsPanel.tsx` + `lib/api/settings.ts` + 后端 `GET /api/settings`
- 沙盒：`features/sandbox/SandboxPanel.tsx`（健康检查 + 会话/任务数量）
- 视觉：统一间距（p-4/6）、圆角（rounded-xl）、边框、阴影、focus 态、按钮层级

## 5. 验收标准
- 四个导航入口可切换，各页可看
- 设置页显示真实模型配置与安全开关状态
- 沙盒页显示后端健康与统计
- 桌面 + 移动（侧栏收抽屉）可用，无横向溢出
- typecheck / lint / build 全过

## 6. 交付结果
- 四入口侧栏导航（创作/短管线/设置/沙盒）+ Lucide 图标已完成；设置页只读展示模型配置与安全开关（后端 `GET /api/settings`）；沙盒页展示后端健康与会话/任务统计；整体视觉升级为清新浅色主题。
- typecheck/lint/build 全过；浏览器实测各页可切换、桌面与移动端无横向溢出（详见子阶段 4 验收记录）。
