# 用户模型选择技术适配

日期：2026-10-04。需求：用户在创作中明确选择生成模型，平台管理配置与用户选择分离。接口、持久化、实际调用参数和前端选择已实现；工程与页面验收通过，见[验收记录](../evidence/用户模型选择/验收记录.md)。真实生成质量仍另验。

## 范围

| 创作流程 | 可选模型 |
| --- | --- |
| 故事短视频 | 文本、图片、按首帧/首尾帧/参考图模式匹配的视频模型 |
| 漫剧 | 文本、图片；角色配音仍为独立声线，成片本地合成 |
| 文艺短视频 | 短文扩写的文本模型、图片模型；长文直接作为内容时不声称调用文本模型 |
| 角色动作短片 | 参考图视频模型 |
| 图片配音口播 | 静态图+配音无视频模型；嘴型模式仅展示独立video_speech，不混入故事视频候选 |

仍使用现有AIHubMix供应商、SQLite和三类模型客户端，无新增常驻服务或第三方密钥。可选项来自已经核验的固定协议能力表与管理员公开名单的交集，不把供应商所有模型直接开放。

缺省使用代码中的当前公开值；设置为空即不公开该类选项。默认模型仍由既有配置确定；默认项不在公开范围时要求明确选择，不静默换模型。修改环境配置需重启后端。已有部署若显式设置旧公开名单，需按上表追加候选才会显示；本地没有覆盖时直接使用代码缺省值。

这与管理员权限是两件事：普通登录用户可以选择已公开的模型；`/api/settings` 与 `/api/admin/sandbox` 由 `ADMIN_USER_IDS` 名单限制，普通用户访问返回403。用户选择不允许更改网关、密钥或平台安全开关。新建故事默认1集，漫剧首期固定1集；选模型不会改变集数或项目类型。

## 数据与接口合同

- `GET /api/models`：普通登录用户可读，返回provider和groups，分组包含label/default/options；不返回网关URL、密钥、安全开关。选项含id/label/description；故事视频选项另含`video={duration_seconds,ratios,resolutions,max_reference_images,estimated_clip_cny}`，用于界面格式校验和费用说明。
- `model_selection` 平铺键为text、image、video_first_frame、video_start_end、video_reference、video_speech，均为可选字符串；不接受任意provider/base_url/api_key等字段。
- 新项目在创建请求中提交选择，保存至SessionMeta的JSON列；旧会话无字段时兼容原默认行为。任务选择纳入任务输入和幂等指纹。
- `PATCH /api/sessions/{id}/models` 只修改本人的后续生成偏好，返回最新会话。活动任务期间409拒绝，并与任务领取使用事务保证互斥。
- 保存偏好不会改写旧产物或自动使旧片失效；真正重生成后沿用产物依赖与版本规则。缓存复用须核对模型，不能将A模型的旧结果当成B模型新结果。
- 实际执行、模型产物和历史版本记录 `model_usage={provider,models}`；只记录该阶段真正调用的模型类别。下一次偏好和历史实际使用分开展示。
- 选择旧素材版本时同步恢复其 `model_usage`；旧版没有来源记录时保留未知，不继承当前版或下一次偏好作为历史来源。

## 客户端协议与验证边界

所有模型覆盖通过单次方法参数传递，不修改共享客户端实例或全局配置。文字结构化重试使用同一所选模型；图片生成和带参考图生成都传所选ID；视频按模式白名单校验。

2026-10-04只读核验：现有供应商凭据的OpenAI模型清单包含Qwen3.5 Plus/Flash。媒体模型的可用状态来自[官方模型目录](https://aihubmix.com/api/v1/models)，它们不一定出现在OpenAI `/v1/models` 列表。

- [Qwen Image2.0](https://aihubmix.com/call/schema/models/qwen-image-2.0/endpoints)与[Pro](https://aihubmix.com/call/schema/models/qwen-image-2.0-pro/endpoints)支持现有文本生图及1–3张参考图接口。
- [Wan2.6 i2v](https://aihubmix.com/call/schema/models/wan2.6-i2v/endpoints)使用 `/ai/v1/videos` 和相同的轮询入口，用于故事首帧及独立10秒嘴型口播。故事请求5秒，`extra={prompt_extend:true,shot_type:single}`；不把Wan2.7或其他模型字段混入。
- [Wan2.7 i2v](https://aihubmix.com/call/schema/models/wan2.7-i2v/endpoints)用于首帧/首尾帧；[Wan2.7 r2v](https://aihubmix.com/call/schema/models/wan2.7-r2v/endpoints)用于参考图。模式不兼容时在调用前拒绝。

本轮以真实目录/官方schema、隔离HTTP请求体测试和浏览器交互验证接入合同，不调用收费模型做画质或性能评测，不承诺模型效果或性价比排序。实际模型样片另行验收。

2026-10-04模型选择批次回归：后端240/240、前端54/54，以及类型/Lint/生产构建通过；普通账号已验证创建选择、已有项目切换、刷新恢复和权限边界。该批收费生成请求未发出，不能据此宣布新版AC07、COMIC07或RAG08真实质量通过；后续批次见[项目状态](../项目状态.md)。

## Seedance 2.5 / Veo 3.1接入合同（2026-10-05）

整体架构、路由、数据库和供应商不变。两者均使用`POST /ai/v1/videos`，持久化返回的id后轮询`GET /ai/v1/videos/{id}`，从`output[].content_url`下载。保留既有单次提交、未知提交不盲重发、原任务查询/下载续接和账号预算机制。

| 模式 | 首帧、首尾帧、多图参考 | 首帧、首尾帧、多图参考 |

| 分辨率 | 720P、1080P | 720P、1080P |

| 多图字段 | `input_references`，明确传项目比例 | `input_references`，明确传项目比例 |
| 音轨 | `generate_audio=true` | 原生音频；不发送schema未定义的音频开关 |
| 720P估算/片段 | ¥9.40 | ¥25.60 |
| 1080P估算/片段 | ¥21.12 | ¥25.60 |

官方来源：[Seedance schema](https://aihubmix.com/call/schema/models/doubao-seedance-2-5-260628/endpoints)、[Veo schema](https://aihubmix.com/call/schema/models/veo-3.1-generate-preview/endpoints)、[Google时长/参考图限制](https://ai.google.dev/gemini-api/docs/veo?hl=en)。2026-10-05只读核验。仅传实际本地图片转成的data URI，不开放视频/音频参考、扩展、编辑、4K或自动时长；不发送Wan专属`prompt_extend/shot_type`。

费用来自[Seedance模型页](https://aihubmix.com/model/doubao-seedance-2-5-260628)与[Veo模型页](https://aihubmix.com/model/veo-3.1-generate-preview)。继续用固定8元/美元预算系数，不是实时汇率。Seedance无视频输入按token计费，官方折算约$0.2344/$0.5273每秒，预算向上按$0.235/$0.528每秒；Veo720P/1080P为$0.4每秒。均非实付或保证上限；账单需后续核对。

`video_contracts.py`统一模式、时长和格式能力；模型目录与客户端共用。整批目标图数在Agent和第一个视频调用前检查，超限不截断；单次客户端也校验。实际片段存`requested_duration_seconds`，不把请求秒数当作探测时长。Veo提示词同步为8秒，单镜头不附全片Agent brief。旧产物与模型偏好不迁移。

跨模型拼接先将片段统一到首段画幅、30fps、H.264/yuv420p、48kHz立体声AAC，保留比例并补边；无音轨补静音，保留原片和实际片段长度。临时文件在成功、失败、取消后清理。此处理不等于叙事剪辑、配乐或人物一致性修复。

验证范围：HTTP替身覆盖两模型三模式、请求字段/时长/预算与原轮询下载；超限先于收费调用；真实FFmpeg覆盖不同帧率/尺寸/有无音轨混合。新模型没有付费出片，质量和供应商实付仍待验；不据此切换默认模型。

## 与任务续接和费用控制的关系（2026-10-04新增）

「继续未完成」使用原执行冻结的输入和模型，不把当前偏好偷偷代入已提交任务。模型或其他相关输入发生变化时拒绝原执行续接，说明需要核对后重新生成；新生成才使用当前偏好。历史`model_usage`仍只描述实际产物来源。

公开模型同时需要可核对价格；价格缺失时选项不会被伪装成免费能力，收费调用在提交前明确失败，用户可以主动选择其他兼容且已配置价格的模型。默认平台/账号月预算500/100元、并发2/1；任务查询与下载复用原调用记录，新提交或明确未受理后的新attempt另行预留。价格表与预算控制不是模型效果排名，也不等于供应商实付账单。恢复接口、配置与最终验证入口见[技术主文档](技术接入方案-汇报评审版.md)、[使用与运维说明](../使用与运维说明.md)和[项目状态](../项目状态.md)。
