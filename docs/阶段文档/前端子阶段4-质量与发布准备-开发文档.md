# 前端子阶段 4 开发文档：质量与发布准备

> 配套：前端技术适配声明、子阶段 1~3 文档。

## 1. 本阶段目标
把前端从"能跑"打磨到"可交付"：响应式、无障碍、多媒体异常态、真实联调、清理告警，并补齐发布说明。

## 2. 范围
### 本阶段包含
- 响应式：390/768/1280/1440 四宽度检查，侧栏在窄屏收成抽屉/顶部切换
- 无障碍：表单 label 关联、按钮可访问名、焦点可见、语义化
- 多媒体异常态：图片/视频加载失败占位（已有）、加载占位防跳动
- 真实后端完整联调（登录→创作→剧本→各阶段产物→短管线→任务→下载）
- 清理 lint / typecheck / build 告警，确认 Console 无持续报错
- 发布说明（README 更新：启动、端口、验收步骤、已知问题）

### 本阶段不包含
- 部署上线（归部署手册）
- 视觉再大改（已定清新浅色，细节微调）

## 3. 用户流程（验收路径）
1. 打开 3030 → 登录 → 工作台
2. 桌面（1280/1440）：左会话列表 + 主内容并排
3. 移动（390）：侧栏收成顶部切换/抽屉，核心操作可触达
4. 走一遍创作 + 短管线，刷新/断线恢复

## 4. 响应式方案
- 主布局：桌面 `lg:flex-row`，移动 `flex-col`；侧栏在移动端变为顶部横向条或抽屉
- 会话列表在移动端横排/折叠
- 表单栅格：移动单列（已有 `sm:grid-cols-3`）
- 触控目标 ≥ 44px

## 5. 实现要点
- Workspace 布局改响应式：外层 `flex flex-col lg:flex-row`；侧栏 `w-full lg:w-72`
- 移动端侧栏默认收起，顶部「会话」按钮展开
- 无障碍：补充必要的 `aria-label`、`alt`、焦点样式（focus-visible）
- 媒体组件已有 loading/error 态，补充固定尺寸防跳动（`aspect-video`）

## 6. 验收标准
- 四宽度（390/768/1280/1440）核心流程可完成、无横向溢出
- lint / typecheck / build 全过，无未解释错误
- 真实联调：登录、创建、剧本生成（充值后）、产物展示、短管线提交、任务下载
- Console 无持续报错
- README 更新启动与验收方法

## 7. 风险与回退
- 风险：真实生成慢（模型商延迟），完整联调耗时
- 回退：联调以"流程可用"为准，生成速度单独记入已知问题

- 无障碍修复：短管线表单 label 关联、侧栏导航/退出 `aria-label`、会话列表改 `<button>` 键盘可操作、产物图 `alt` 按角色名/序号生成。
- 修复运维脚本 `manage_invite_codes.py list` 在 SQLite 迁移后的 dict 排序崩溃。
- 前端 README 改写为项目说明，根 README 同步子阶段 1~4b 完成。
- 四宽度（390/768/1280/1440）实测无横向溢出；Console 0 报错；设置页/沙盒页真实展示；typecheck/lint/build 全过、后端 57 项测试全过。
