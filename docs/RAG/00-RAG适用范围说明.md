## 1. 结论

AI造梦机的故事短视频与漫剧共用创作知识库。知识库为两条主链路的剧本和分镜 / 镜头对白提供角色、世界观、前情、风格与品牌事实，采用本地中文语义检索；用户按项目主动选择资料库，生成前检索，输出保存来源版本与片段。共用指同一账号可复用自己的资料库，不是跨账号共享。

## 2. 当前范围

1. 支持 `.md`、`.txt`、可提取文字的 PDF，单文件 5MB；扫描件暂不做 OCR。
2. 按账号组织多个资料库；故事 / 漫剧每个项目最多选择 3 个。未选择时沿用各自创作行为。
3. 固定约束始终注入，普通资料进行语义检索；约束预算超限明确报错。
4. 原文版本与生成时的来源快照留存；资料更新或移除后提示，用户决定是否重新生成。
5. 检索测试完全在本地执行；实际剧本或分镜生成时，命中片段及固定约束随请求发送至现有模型网关。

本版不扩展网页抓取、多模态资料检索、OCR、通用聊天机器人或三种快捷短片的 RAG。来源面板表示“提供给模型的资料”，不是逐句归因或事实正确性的保证。检索空结果与检索服务故障分别处理。

用户可选文本生成模型不会更换本地 Embedding 模型；资料来源快照与实际生成模型分别记录。RAG 独立留出集 Recall@5 = 0.80，H01/H07/H08 仍未通过；新增漫剧或模型选择的工程验收不覆盖这些失败，也不代表 RAG08 真实 LLM 质量已验收。

## 3. 与现有「素材库」的区别

本人生成图片列表与 reuse **不是 RAG**：它是文件资产索引 + 归属校验，无向量检索、无知识切片。
