# 本地创作 RAG 检索评测方案

版本：`rag-creation-zh-v1`。评测对象是创作知识库的检索层，决策是能否进入本地工程使用；真实 LLM 是否正确采用材料及最终画面质量另行验收。使用 `model-evaluation-script` 的目标、覆盖、规则、批量和证据门，先冻结场景再运行，不以排行榜作为结论。

## 目标和边界

| 项目 | 冻结值 |
| --- | --- |
| 业务任务 | 故事创作前从本人选定的人物、世界、剧情、视觉和品牌库查找依据，固定约束始终保留 |
| 评测单位 | 一条查询及其本次返回的文档块、版本、约束和错误状态 |
| 输入 | 合成中文资料、账号、选定库、查询；不向检索器传答案或评分标签 |
| 输出 | Top-5 检索命中、可回溯版本、固定约束、耗时；拒绝或空结果照实记录 |
| 通过线 | 有答案 case 的宏平均 Recall@5 ≥ 0.85；必要固定约束覆盖率 100%；关键 case 全通过 |
| 否决线 | 跨账号或跨选定库泄漏、召回被删除或错误版本、丢失必要约束、空查询返回普通命中、无答案强召回 |
| 不在范围 | 生成模型效果、人工审美、付费 API、生产容量、真实资料的分布泛化、提示注入后的 LLM 行为 |
| 重复和重试 | 每条查询 2 次，0 次自动重试；记录首次与热缓存耗时，不宣称生成稳定性 |
| 费用和数据 | 本地 embedding，无付费 LLM；临时目录与合成账号，不触碰用户知识库 |

阈值为本轮小规模工程门槛，不能推导线上创作提升。评测集只有 18 条，五个内容领域各自没有达到大样本覆盖；通过也不代表完整生产验收。检索候选、实际依赖版本、模型修订、切分、分数门槛、上下文预算和 source hash 由 runner 写入每份证据。不得在看到结果后降低门槛；若实现或评测集修订，使用新证据批次并保留失败结果。

## 覆盖矩阵与固定评测集

评测集：`backend/tests/fixtures/rag_eval.json`，15 份合成资料、6 个库、2 个隔离账号。资料有明确标题、来源、内容与更新动作，答案标签只用于评分，不传入检索输入。

| 场景 | 数量 | case_id | 观察点 |
| --- | ---: | --- | --- |
| 人物、世界、剧情、风格、品牌语义与同义表达 | 8 | R01–R08 | 预先标定资料能否进入前 5 个普通检索命中 |
| 剧情、世界、品牌固定约束 | 3 | R09–R11 | 相关证据及强制约束是否保留，禁止条件不被相似度过滤 |
| 无答案、空文本与纯空白 | 3 | R12–R14 | 空结果或明确无证据；约束与普通命中分开计量 |
| 选库和账号隔离 | 2 | R15–R16 | 返回来源不能超出本人已选择的授权库 |
| 最新版本和删除失效 | 2 | R17–R18 | 更新后只取当前版；删除资料不能继续命中 |

这些题目来自项目创作流程的合成材料，既有直述也有同义问法；没有使用用户真实资料或外部生成答案。R07 是多库复杂场景，R12–R18 覆盖边界与工程否决项。所有非空、合法选库的查询均检查各库必载约束，R09–R11 额外使用与约束冲突的创作请求。安全上传、并发和 API 权限等另由后端回归覆盖，本 runner 独立检查实际语义检索结果。

## 评分规则与校准

| 规则 | 计算方法 | 正例 / 反例 |
| --- | --- | --- |
| RET01：Recall@5 | 前 5 个普通命中的不同 document_id 与 expected_documents 交集大小 ÷ 该 case 的 gold 数量；仅在 gold 非空时计均值 | R07 两份资料均召回得 1；只召回一份得 0.5 |
| CON01：必要约束覆盖 | 每条必要约束的原文均出现在固定约束区；不能把相似命中当作固定约束 | R10 返回无机动车原文通过；仅命中“潮汐城”不通过 |
| SEC01：范围和归属 | 所有普通命中与固定约束均来自本次允许的本人库；R16 明确拒绝外账号库 | 返回 private_code 即否决；错误码和无数据返回照实记录 |
| VER01：版本与删除 | 版本更新 case 的命中版本等于当前文档版本且包含新事实；删除项不得出现 | R17 二十七岁、银色且 v2 通过；旧 v1 失败 |
| EMP01：空与无答案 | 普通命中数为 0；固定约束可独立存在，不当作问题答案 | R12 返回固定规则但无普通事实命中通过 |
| DATA01：证据完整 | 必需 case 无缺失；模型/版本/语料 hash/查询/命中/耗时/异常均有记录；运行异常不可补分 | 失败批次仍存完整错误；漏跑则 STOP |

评分使用确定的 ID、原文与版本断言，没有 LLM Judge，也不把生成回答交给检索模型自评。先用 R01、R10、R16、R17 作为普通、约束、拒绝和版本锚点运行试验，检查映射、分母和错误记录，再执行全量。自动断言不能替代 skill 所要求的真实生成效果人工独立试标；本轮不宣称人工双评、主观效果校准或真实生成验收已通过。若 gold 存在分歧，应记录 NEED_REVIEW 并冻结结论，不能用主观补分。

## 本地运行和证据

入口是 `backend/scripts/evaluate_rag.py`，必须显式指定 `--output` 到本项目 `docs/evidence/RAG/`。runner 在系统临时目录创建库和索引，退出后清理；只读取可共享的模型缓存。依赖安装由后端任务统一处理，runner 不安装包，不读取密钥，不连接付费模型。

证据 JSON 包含 run_id、UTC 时间、评测集 hash、冻结语料 hash、实际依赖精确版本、embedding 模型标识及缓存文件 hash、检索配置、原始查询、hits（document/version/chunk/score/text）、constraints、每次耗时、错误、逐项断言、聚合门禁及失败 case。输出为本地 RAG 工程通过、不通过或 STOP；没有成功执行时不得写通过分数。

```sh
cd backend
.venv/bin/python scripts/evaluate_rag.py --output ../docs/evidence/RAG/rag-eval-pilot.json --case-ids R01,R10,R16,R17
.venv/bin/python scripts/evaluate_rag.py --output ../docs/evidence/RAG/rag-eval-v1.json
```

首次模型载入与索引构建时间单列；检索 p50/p95 只描述本机合成小库，不当成生产 SLA。可添加 `--score-diagnostics` 记录不经过分数阈值过滤的诊断命中，每次诊断与实际评分结果分开保存，不参与分数，也不改变原查询的通过判定。任何安装失败、模型不可用或接口错误写入 evidence 并 STOP，不降级成关键词搜索或假 embedding。模型、切分或检索策略变化时绑定新候选配置和新运行批次；gold、评分规则或验收门槛变化则升级评测版本，保留旧证据。真实 LLM 用证据回答与创作的质量仍需单独的效果评测。

原开发集 gold、0.85 召回线、100% 约束与关键门槛未修改。检索过滤阈值由开发集失败样例校准为 0.48，因此该集复测只证明修复了已观察到的开发问题，不是独立泛化证据。两次过滤候选及原失败结果均保留。

独立 holdout 是 `backend/tests/fixtures/rag_eval_holdout.json`：6 份新资料、4 个新库、8 条新查询，先冻结后运行，冻结时间为 `2026-10-03T16:35:38.936Z`，文件 SHA-256 为 `d8e38522e2ef27361e1741f216d1fa1f4e99b819e5c9d73d95ad0b405ff0c37e`，执行开始时间为 `2026-10-03T16:35:52.879588Z`。没有用 holdout 再调过滤阈值，原文与答案标签没有事后修订。

失败证据与边界：

- R01“女主为什么不敢靠近水很深的地方？”人物依据分数 0.498；R04 投递任务依据分数 0.550，均被原 0.55 阈值过滤。新候选保留了这两条相关依据，同时原跨域无答案 R12 无普通命中。
- H01“男主为什么会主动避开忽然很响的地方？”正确人物资料分数 0.453，被新 0.48 阈值过滤，说明新的意译仍有漏召回。
- H07 问人物母亲姓名，返回人物档案分数 0.651；H08 问茶杯售价，返回产品说明分数 0.755。这些文本与问题同域，却没有所问姓名或价格；按预先冻结的空命中期望，两题均失败。相似分数不是答案充分性的判断，不能把 `matched` 宣称为已回答。

开发集的 40 次必要约束检查全部覆盖，两个非空隔离场景均符合范围和归属，更新 / 删除场景没有召回旧版或删除资料；这些是本轮小样本观察，不是所有用户资料的安全性或准确率证明。校准开发集检索 p50 / p95 为 4.65 / 8.10 ms，独立 holdout 为 5.86 / 9.64 ms，模型已在本机预缓存，不含首次下载，也不代表生产容量。

**决策：开发集工程门槛通过，独立小样本检索效果未通过；可作为有条件的本地工程内测，不宣布完整 RAG 效果验收或生产上线。** 内测必须允许用户核对来源并确认事实，证据不足时不能据此编造姓名、价格等事实；真实 LLM 能否遵守这种边界尚未评测。下一轮保留本集回归，扩展新资料、意译和同域无答案，独立评估答案充分性及拒答，再决定是否可扩大使用。所有执行使用临时库和真实本地 embedding，0 次付费模型调用，没有写入用户真实知识库。
