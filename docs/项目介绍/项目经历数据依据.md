## RAG 数据补充

开发集与独立集均采用合成小语料。开发集最终 18 项用例执行 36 次，独立集 8 项执行 16 次。独立集只有 5 项计入召回指标，Recall@5 = 4/5 = 80%；H01、H07、H08 为失败用例，整体门禁未通过。正文表达的是评测体系与执行规模，未宣称检索质量全部通过。

开发集校准前后使用相同资料和用例，阈值由 0.55 调至 0.48，Recall@5 从 9/11 到 11/11；这属于同集调参，未写成泛化提升或业务效果提升。

来源：[开发集最终结果](../evidence/RAG/rag-eval-v1-calibrated-20261004.json)、[独立集结果](../evidence/RAG/rag-eval-holdout-v1-20261004.json)。
