# 雨夜归途 · 录屏材料

在项目根目录执行：

```bash
./demo.sh reset
```

命令重置两份作品并启动服务，打开终端输出的链接即可；本地邀请码 `DEM23456`。已有登录保持有效。每次录制前再次运行同一命令，然后刷新／打开新链接。首次构建稍慢；无页面变化时复用录屏专用 `.next-recording` 构建。命令只管理自己启动的服务，若端口被其他程序占用，会停止操作而非强杀。

只处理 `.runtime/release-demo/data` 中该演示账号的作品，旧列表隐藏，数据库备份存放在 `.runtime/release-demo/backups`，旧素材仍在。正式 `data/`、其他账号、原人工评分与历史答复不变。重置后的作品编号会变化，勿收藏旧编号链接。

## 两份作品

- **雨夜归途**：一只黑色卷毛小狗墨豆，陪主人走过雨后的灯街。剧本、角色场景、分镜、参考图、视频与成片均已准备并完成；打开显示“剧本”以便先展示检查，可直接点“成片”播放。完成作品按现有规则不能再重生成，局部换图在第二份作品演示。这些预备状态不代表新增真人评分。
- **雨夜归途 · 继续制作**：同一故事，前四阶段已完成，在第二个视频镜头中断。点击“继续未完成阶段”沿用已有输入和素材继续制作；不是重新建作品。

本地图片来自同一段实拍，单张重生成会更换为下一张预备帧。图片不会根据新提示词产生新内容；“换个角度”用于展示局部替换和版本保留。实拍约 8.88 秒，无原声，录屏可配自己的讲解。来源与许可见 [素材说明](../../assets/demo-rain-dog/README.md)。

## 两分钟点击顺序

| 时间 | 点击 | 展示内容 |
| --- | --- | --- |
| 0:00–0:20 | 打开新链接，停在《雨夜归途》的“剧本” | 自动看到 3 处问题：牵引绳绝对保护、灯光导致积水消失、灯光下绝对安全；每处都有位置和修改建议。 |
| 0:20–0:35 | “成片” → 播放 | 展示真实雨夜遛狗短视频。 |
| 0:35–1:00 | 左侧《雨夜归途 · 继续制作》 → “继续未完成阶段” | 展示保存的故障位置、前置素材及恢复后视频制作完成。先不合成最终成片。 |
| 1:00–1:25 | “角色场景” → 墨豆图下“修改提示词 / 重新生成” → 填“换个角度” → “重新生成这张图” | 角色图换成另一张预备照片，场景图保持不变；下游内容按原规则提示待更新。 |
| 1:25–1:45 | “阶段版本” → 版本 1 → 版本 2 | 展示新旧版本切换，原图可以找回。 |
| 1:45–2:00 | “确认角色场景…” | 展示阶段确认，进入下一待更新阶段；现有分镜仍有效时会跳到参考图。 |

需要展示编辑后复查时，可另录一段：在第二份作品恢复后，到剧本“编辑内容”中删除三句无依据表述，保存后展开“查看检查历史”。不要在失败恢复前改上游内容，否则现有保护机制会要求重新生成。

所有问题由原冻结检查器实际计算，没有写死提示或放宽检查规则。所有作品和素材用于功能录屏，不计入模型质量、真人评分或既有回归成绩。
