## 动作迁移的排查与修复

- 首次失败为「The read operation timed out」（视频生成调用）。
- 诊断确认 `wan2.7-r2v` 模型有效、可正常出片；失败源于网络波动 + 偶发慢。
- 加固视频客户端：提交/轮询对瞬时失败（超时/连接/5xx）有限重试、4xx 快速失败；新增 3 项专项测试。
- 加固后补跑动作迁移成功（120s，成片约 2.3MB）。

## 质量边界（如实标注）

- 动作迁移：用「角色参考图 + 提示词」生成，**非像素级动作迁移**；真实迁移能力待模型侧进一步核验。
- 数字人口播：**静态人物图 + 配音，无嘴型同步**；真实嘴型同步待后续模型。
