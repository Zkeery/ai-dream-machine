# 第二刀短管线真实冒烟方案

2026-09-23。目标：验证三条短管线在真实模型下能否跑通并出片；动作迁移、数字人口播的真实能力边界如实核验。

## 范围与预算

- 每条管线各跑 **1 条**样例，共 3 条；预算上限 **≤ 10 元**，失败即停、不自动重试。
- 复用第一刀真实生成的素材作为动作迁移/数字人口播的输入（角色图、动作视频）。

## 样例

| 管线 | 输入 | 期望产物 |
| --- | --- | --- |
| 文艺短视频 | 灵感「雨夜的老街，一盏孤灯下，一个人撑着伞慢慢走过。」 | 图文配音成片 |
| 动作迁移 | 角色图 + 动作视频 + 提示词「人物微笑着向镜头挥手」 | 角色动作视频 |
| 数字人口播 | 人物图 + 文案「欢迎来到AI造梦机…」 | 配音口播视频 |

## 判定

- 技术判定：任务不抛异常、成片落盘且非空、可播放。
- 质量判定：由产品经理目测打分（沿用 D7 口径：符合描述/质量可用/风格一致/无违规）。
- 动作迁移、数字人口播的「像素级动作迁移」「嘴型同步」在结果中如实标注是否达成，不冒充。
