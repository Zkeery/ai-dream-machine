## 三、验收：6 阶段主流程（真实生成，会花余额）

1. 用任一账号登录，输入创意（例：`一只流浪猫在雨夜被好心人收留`），点「开始创作」
2. 点「生成当前阶段」→ 看到剧本（片名/梗概/角色/剧集）
3. 确认无误后点「确认进入下一阶段」，逐阶段生成：角色场景图 → 分镜 → 参考图 → 视频片段 → 成片
4. 每阶段可「生成当前阶段」重做
5. 最后「下载成片」拿到视频
6. 重启后端，确认进度还在（会话落盘）

## 四、验收：三条短管线（真实生成，会花余额）

左侧「短管线」区，三个入口：

1. **文艺短视频**：输入灵感（如 `雨夜的老街，一盏孤灯下，一个人撑伞慢慢走过`）→「生成」→ 任务列表看进度 → 完成后「下载」
2. **动作迁移**：上传一张角色图 + 一段动作视频 + 填提示词 →「生成」→ 下载
3. **数字人口播**：上传一张人物图 + 填口播文案 →「生成」→ 下载

> 任务在后台跑，可离开页面；回来任务列表显示「完成」即可下载。失败会显示原因，可重新提交重试。

## 五、判断标准

- 登录/隔离：未登录进不去；两个账号各看各的
- 主流程：从创意走完 6 阶段到成片，不卡死，可下载
- 短管线：一次输入 → 后台跑 → 出片可下载
- 质量：成片能看、风格基本一致（D7 标准已定：每条 4 维度平均 ≥ 2 分且无 1 分项；2026-10-11 起改为五维加合规红线一票否决，见 `docs/Agent/02-评测标准.md`）
