# 整体链路自查 · 2026-10-04

结论：当前项目具备可运行的本地 MVP 主流程；故事短视频、漫剧、快捷工具与知识库的工程接线有代码和测试支持。它尚未达到所有创作能力完整、真实生成质量全部验收、多用户长期稳定运行的状态。

本轮核对了实际源代码、隔离自动化测试、真实本地 FFmpeg、重启后的运行服务与浏览器页面。未新增付费模型调用，未用本地替身结果冒充真实 AI 成片。可视化架构、四层分析与证据索引见 [完整自查报告](report.html)。

## 本轮发现与处理

| 问题 | 影响 | 本轮结果 |
| --- | --- | --- |
| 生图下载失败和视频提交响应丢失会重提生成 | 一次操作可能产生多次模型生成及费用 | 已修：付费图像/视频 POST 结果未知时停止自动重提，图片 GET 下载单独有限重试 |
| 文本模型明确返回 5xx 时未按配置重试 | 可恢复异常直接中断阶段 | 已修：明确的 5xx 有界重试；网络中断等结果未知情形不自动重提 |
| 快捷工具输出 H264 yuv444p、奇数宽高 | MP4 文件生成成功仍可能无法在部分浏览器/手机正常播放 | 已修：图片配音输出 H264/yuv420p/AAC，补足偶数边界、保持画面比例，支持 faststart |
| 通用 FFmpeg 子进程无完成时限与取消回收 | 失败或取消后可能长期占用任务和进程 | 已修：分别设合成/拼接/抽帧时限，超时和取消时终止并回收进程 |
| 媒体预览切换后继承旧错误 | 新成片已加载仍显示失败 | 已修：媒体状态按项目和路径隔离，忽略并释放旧请求的迟到结果 |
| 本地漫剧验收脚本接口落后于模型选择接口 | 离线验收脚本发生 model 参数错误 | 已修：LocalLLM 同步接收并记录 model 参数 |

## 当前范围与未闭合事项

1. **故事主链路**：剧本→角色场景→分镜→参考图→视频→拼接成片，有阶段确认、修改、版本和下游失效控制。当前故事成片仍以视频拼接为主，完整配音、配乐和字幕制作不能按漫剧能力类推。首帧和多图参考有用户入口；首尾帧需要真实尾帧，普通界面暂未开放完整配置流程。
2. **漫剧主链路**：剧本→角色场景→镜头对白→漫画镜头→角色配音→运镜字幕 MP4，独立于故事链路。隔离工程闭环与真实 FFmpeg 渲染已测；完整真实模型漫剧样片、人物一致性、在线配音效果仍待验收。
3. **快捷工具**：文艺短视频和图片配音口播可走图片加音频合成；口播不含嘴型同步。角色动作短片目前仍要求动作视频，但模型请求未使用动作序列，不能验收为动作迁移完成。
4. **知识库**：上传、解析、嵌入、索引、按账号和版本检索、来源回溯及删除过滤有工程验证。历史独立留出集 Recall@5=80%，H01/H07/H08 失败，检索质量尚未达标；本轮未重跑或改写该历史质量结论。
5. **执行恢复**：SQLite 保存任务、事件、输入、版本和确认状态。进程重启后，未完成任务标为中断，用户可决定后续操作；供应商异步任务 ID/产物 URL 未持久化，尚不能跨重启接回供应商任务。手动重新生成仍可能产生新费用。
6. **多人运行**：目前使用后端单工作进程、本地 SQLite、本地 Qdrant 和进程内异步任务。没有全局/账号并发额度与实际费用拦截；多工作进程还存在部分“检查后保存”的竞态边界。当前架构适合本地 MVP，不能直接推定可扩展为多人生产服务。
7. **启动脚本**：`start.sh` 尚无端口占用预检，退出时使用 `kill 0` 影响整个进程组。本轮使用明确的本项目进程 PID 启停；该脚本问题列为待修，未改动启动体系。
