| Badcase | 实际证据 | 影响 / 下一步 |

| H01：用意译描述人物避开巨响 | 正确资料相似度 0.453，小于 0.48 | 普通资料有漏召回；重要设定使用固定约束，后续扩展独立语料评估混合检索或重排 |
| H07：问资料中未给出的人物母亲姓名 | 返回相关人物片段，但没有姓名，约 0.651 | 相似检索不能判断“是否足以回答”；原 EMP01 门槛失败，不能把片段当答案 |

这些失败保留为下一轮回归。前端提示与 Prompt 约束不等于已经解决模型幻觉；真实 LLM 的资料使用、证据充分性和无 RAG / 有 RAG 对照仍待评测。小样本检索耗时不作为生产 SLA。
