## 3D 与静态降级

| 检查 | 结果 |
| --- | --- |
| WebGL 初始化 | 实际页面 `data-render=webgl`，图形错误码 0 |
| 鼠标视差 | 相机从中心移动到非零坐标，门框与背景具有不同深度 |
| 窗口尺寸切换 | 390 → 768 → 1280 → 1440 → 390 往返检查；静帧与图形图层保持相同尺寸与位置，手机裁切焦点 0.735、桌面 0.5，WebGL 错误码均为 0 |
| 暂停与恢复 | 暂停后相机回到中心，帧数保持不变；恢复后帧数继续增加 |
| 背景切换 | 切换至云上之城，场景图片与选中标签同步变化 |
| 减少动态 | 模拟 `prefers-reduced-motion: reduce` 后停止帧更新，暂停控制不可操作；仍可使用创作表单 |
| 图形上下文丢失 | 模拟 `WEBGL_lose_context` 后进入 `fallback`，暂停入口隐藏，静帧图片和输入仍可用；重新加载恢复 WebGL |

画面由原创静帧、分层图像平面、有厚度的三侧光门框、3D 光点与轻微海面扰动组成，不包含可漫游的完整 3D 地形。场景限制为 30fps、DPR 上限 1.5；页面隐藏、场景离屏及减少动态时停止动画，组件卸载时释放图形资源与监听器。
