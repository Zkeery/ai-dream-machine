本地生成：

1. 把 `.env.example` 复制为 `.env`，填入 `AIHUBMIX_API_KEY`。
2. `python3 -m venv backend/.venv && backend/.venv/bin/pip install -r backend/requirements.txt`
3. 确认本机有 `ffmpeg`。
4. 在 `backend` 目录执行 `.venv/bin/python scripts/run_d7_round.py`。只跑一条时加 `--only S1`。
5. 成片路径：`docs/evidence/D7-角色一致性/output/<样本ID>/final.mp4`。定妆图在同目录的 `sheets/`。

生成配置：角色、场景和道具先按定妆提示词出图（默认 `qwen-image-2.0`），每个镜头再用参考图模式（默认 `wan2.7-r2v`）带上这些图。16:9，720P，每镜请求 5 秒。费用受 `.env` 里的月预算限制，超限会停，不会自动加预算。
