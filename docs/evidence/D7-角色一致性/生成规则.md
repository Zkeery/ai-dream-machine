# D7 生成规则（依据 S1 三轮结果）

更新：2026-10-11。依据：`output/S1-wan27`、`output/S1-kling-v1`、`output/S1-kling-v2` 三版样片，以及 2026-10-11 S1 成片（可灵 1080P）的评分反馈。

## S1 这几轮的结论

| 轮次 | 模型 | 观察 |
|---|---|---|
| S1-wan27 | 图片 qwen-image-2.0，视频 wan2.7-r2v 720P | 画面偏灰，动作有跳帧感。 |
| S1-kling-v1 | 图片 Seedream 5.0 Pro，视频 kling-v3-omni 720P | 画质更好，多镜头角色基本一致，但 720P 偏软。 |
| S1-kling-v2 | 同上，第 1、2、5 镜改为 1080P 重跑 | 镜头里混用了 720P 和 1080P 两种分辨率；第 2 镜开头只露出耳朵尖，第 5 镜女孩头顶被切，鞋子变成了黄色靴子。 |
| S1（2026-10-11） | Seedream 5.0 Pro + kling-v3-omni，5 镜全部 1080P | 评分时发现：第 4 镜猫的眼睛变成绿色（提示词和定妆图都是琥珀色）；猫的头抽动了两下；第 5 镜毯子把猫头整个盖住（提示词只写了「盖在猫身上」，旧模型生成正常，换可灵后才出现）。 |

问题归因：

1. **不写景别，主体容易被裁切。** 提示词里没有写清景别和构图时，主体常常贴着画面边缘，或者被切掉一部分。
2. **动作幅度要适中。** 幅度太小，画面像幻灯片；幅度太猛（比如「用力甩头」），会出现动态模糊，主体也会出画。
3. **定妆图没画到的地方，模型会自己乱加。** 比如定妆图里看不清鞋袜，成片里就可能冒出别的鞋子。
4. **合成不能硬转帧率，码率不能压太低。** 把原生 24fps 硬转成 30fps 会带来顿挫感；码率压得太低会让画面发糊。
5. **遮盖、接触类动作和关键颜色不能只写一半。** 不同模型对同一句话的理解不同：「盖在猫身上」旧模型理解成盖住身体，可灵理解成连头一起盖住；眼睛颜色只在定妆图和部分镜头里写过，可灵在某一镜里就改成了绿色。头部动作没写「平稳、连续」时，还会出现抽搐。

## 统一规则

1. **模型与分辨率**：统一用可灵 `kling-v3-omni` 1080P（pro 档）出视频，Seedream 5.0 Pro 出定妆图。同一条片子里不混用分辨率。
2. **每个镜头的提示词必须写全**：
   - 景别；
   - 主体完整入画，并尽量位于画面中央；
   - 一个清楚、幅度适中的动作；
   - 镜头怎么运动；
   - 主体脸部清晰对焦；
   - 服装和鞋袜与定妆图一致。
3. **人物定妆图要画全身**，包括鞋袜。
4. **负面提示词**：在原有基础上统一加上「主体被裁切、出画、滑步、画面静止、动态模糊、失焦」。
5. **遮盖、接触与关键颜色**（2026-10-11 补充）：
   - 写遮盖或接触类动作（盖毯子、戴头盔、手扶、过肩前景等）时，必须写明遮盖范围（例如「只盖到脖子以下」），并写明角色的头和脸始终完整露出、手不碰头部。
   - 眼睛、毛色、服装等关键颜色要在每一个出现该角色的镜头里重复写，不能只写在定妆图里；同时把「眼睛颜色变化」以及最容易被换成的颜色（如绿色眼睛、蓝色眼睛）写进负面提示词。
   - 头部动作写明「平稳、连续、只做一次，没有抖动和抽搐」，负面提示词加「头部抽搐、头部抖动、动作重复、闪动」。
6. **合成**：按原生 24fps 合成，不转帧率；如果第 0 帧就是定妆图，就去掉这一帧；保留一份高码率原片（`final-master.mp4`，CRF 约 16），另出一份小于 15MB 的预览版（`final.mp4`）。
7. **流程**：每条样片只跑一次，跑完按 D7 五维加合规红线标准人工打分（见 `docs/Agent/02-评测标准.md`；本批无配音字幕，该项记「不适用」）。不通过的记为 Bad Case，攒齐后统一修改规则，不针对单个镜头零碎补镜。
8. **成本**：每轮先定预算硬上限，并在代码里做检查：每次调用前，已花费用加上这次的预估，如果会超过上限就停下来。只有平台报错（5xx、超时）可以重试，每次调用最多重试 1 次。
9. **无标志、无文字**（2026-10-11 补充）：所有服装、道具、车辆、箱包、招牌，在定妆图和每个镜头的提示词里都要显式写「无标志无文字」（纯色、无印花、无品牌、无文字或数字），并在负面提示词里加上「品牌标志、商标、logo、服装上的文字、印刷文字」以及最可能被套用的真实品牌名。否则模型会自己加上真实品牌。案例：S5 骑手定妆图没写这一条，Seedream 在夹克前胸和背后印了「美团」「美团外卖」，被内容审查判为不安全并拦截（同时提到可识别人脸的肖像风险，因此真人风格角色的定妆图还要写「虚构角色，写实风格但不像任何真实名人」）。
