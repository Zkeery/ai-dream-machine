# AI造梦机 · 三项补强与真实样片验收

日期：2026-10-04。验收对象：当前本地版本的故事短视频、漫剧视频、任务恢复、并发与费用控制。

**结论：两条链路的真实小样工程闭环通过，内容质量仍需迭代。** 本轮完成真实模型调用、配音、媒体合成、导出与浏览器播放；没有把小样本通过扩写成量产稳定、商业可用或正式质量通过。

## 3. 真实故障与恢复验证

### 参考图被明确拒绝

故事第一张参考图成功，第二张返回 HTTP 402；随后在供应商后台观察到可用余额约 $0.02。用户补充余额后继续验收。

旧记录在同时满足“本次执行最后一次提交、执行错误精确含 402、无供应商 ID/结果 URL、对应账本明确 rejected”时进行受控核对。恢复沿原输入、原顺序执行：第一张沿用已生成结果，第二张产生一个新的 attempt 和 call_id。旧拒绝记录保留，新调用独立预留费用。三个记录最终为 completed / rejected / completed；没有重新生成第一张。

### 视频生成期间主动中断隔离进程

第一个视频的供应商任务 ID 已持久保存、状态为 `job_pending` 后，结束本轮隔离的验收进程；正式 3030/8030 服务和用户作品未受影响。新进程执行中断恢复，再用原输入查询原任务并完成剩余镜头。

最终仅有两个视频供应商作业和两笔对应视频生成费用，分别对应两个镜头。没有重复提交第一个镜头。该验证包含真实远端异步任务与进程重启，API/SSE 层另有自动化集成测试。

### 超时与其他边界

漫剧第一次文本请求超时，服务保留未知结果及预算预留，没有在客户端自动重复请求。补充余额后单独记录了一次新的文本生成。尚未核实前一次供应商实付，因此保留 `uncertain`。

408/409/425/5xx、超时或供应商异步失败不能被当作未受理；已知任务可继续查询，未知且无任务号的提交需核对。Edge TTS 没有供应商任务级续接，失败时仍从该句重新合成。恢复阶段可能再次执行审核检查，这些调用正常入账。

评分者：Codex，基于原始产物、四帧抽样、浏览器播放和媒体数据；不是双人校准的正式内容评审。详细观察见[质量记录](quality-review.json)。

| 检查项 | 发现 | 处理与边界 |

| 场景内容 | 漫剧灯塔场景图错误出现女性人形，原因是场景误用人物提示词 | 新增独立环境提示词，只对 `l1` 定向重绘；角色图和已编辑分镜保留。修复后的场景未见多余人物 |
| 配音声线 | 漫剧分镜曾输出不支持的 `young_male_calm`，结构校验要求修复后才继续 | 声线目录动态来自实际 TTS 支持列表，禁止臆造 ID；本次最终选用云希 |
| 角色与物件 | 深蓝外套、红围巾基本连贯；漫画中信封颜色/封口细节仍有变化 | 局部细节一致性需迭代，不标完全通过 |
| 画面真实感 | 故事灯塔与人物尺度、轮廓合成感和环境纹理不够自然 | 保留为质量问题；工程可播放不代表达到发布审美标准 |
| 漫画风格 | 漫画人物与偏摄影背景的风格统一性不足 | 需改进场景风格约束及参考图融合；不列为量产通过 |
| 运镜与声音 | 有可见画面变化、字幕和非静音音轨 | 抽帧不能排除短时瑕疵；声音自然度、情绪和全片审美仍需人工评价 |

本轮不为消除所有视觉问题无限重生成；范围内已经修复确定的提示词/参数传递错误，保留失败版本和人工改稿记录。没有伪造首轮通过率、节省人力或商业转化数据。
