## 冻结范围

- 决策：当前双主链路能否完成小样验收；不是多模型选型、稳定性统计或全面上线承诺。
- 对象：当前项目固定工作流 + Prompt + 基础文本/图片/视频模型 + 在线配音 + 本地合成。
- 案例 STORY01、COMIC01：雨后的海边灯塔，一位穿深蓝外套、系红围巾的青年林舟，拾起一封信，望向亮起的灯塔。只一名角色、一处场景、一集、最多两个镜头。故事采用16:9、720P、首帧视频；漫剧采用9:16、720P、短对白与基础运镜字幕。
- 模型：qwen3.5-plus、qwen-image-2.0、wan2.7-i2v；审核沿用 qwen3-vl-flash，不能为了通过测试关闭审核。模型别名的供应商底层版本未返回时记未知，不自行补造版本号。
- 每阶段单独执行与检查；剧本/分镜超出范围时先保存原输出，再通过产品编辑能力缩减并记录人工修改，绝不直接批量出图。
- 默认4096输出tokens、temperature0.7，结构化校验和有界重试遵循本轮代码；所有调用计入费用台账。seed未支持不假装固定。
- 本轮独立验收目录限定估算预算50元，属于既有500元/月计划内的小样支出。价格采用官方模型页2026-10-04快照，预算换算系数8人民币/美元，仅用于保守估算；供应商实付未提供则为null。禁止将预留释放称为退款。
- 每案例一次完整首轮运行；失败重试逐次登记，不只保留成功。没有多次独立运行，不评价稳定性。原模型输出和导出媒体存本项目验收目录，不上传外部平台。
