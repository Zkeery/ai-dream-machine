# AI造梦机 · PRD V1.0

> 一句话定位：**从一句创意到一部完整成片的 AI 短片 / 短剧创作系统**。
> 参考项目：小云雀（xiaoyunque），完整复刻其能力——6 阶段主流程 + 3 条一次性短管线，最终做成可对外多人使用的产品。
> 定稿日期：2026-09-23。本文只写产品契约；技术架构在阶段 1 用蓝图工具推导。

---

## 1. 目标用户与核心任务

### 1.1 目标用户
- 主要：短视频 / 短剧创作者、个人自媒体、内容创作者（不会专业剪辑也能出片）
- 次要：小团队内容工作室
- 最终形态：**对外多用户产品**（需登录、账号隔离）；第一版先本地跑通全链路

### 1.2 核心任务
用户只给一句想法、一段梗概或模糊概念，系统自动走完「剧本 → 角色/场景 → 分镜 → 参考图 → 视频 → 成片」全流程，中间可确认、可修改、可续写，最终拿到一部**完整成片（含剪辑/配乐/字幕）**。

### 1.3 一句话价值
把零散的「文生图 / 文生视频」能力，升级成一条可协作的 AI 导演流水线，让没有专业剪辑能力的人也能从想法直接产出成片。不是一次性出片的黑盒，而是每个关键节点都可视化、可编辑、可在修改后继续生成。

## 2. 输入、过程和产物

### 2.1 输入
- **主流程**：一句创意 / 一段梗概 / 模糊概念；可选视觉风格、视频比例、分辨率、剧集数
- **短管线**：
  - 文艺短视频：创作灵感或完整文案
  - 动作迁移：角色参考图 + 动作视频 + 提示词
  - 数字人口播：人物图片 + 口播文案

### 2.2 过程中用户看到 / 确认什么（主流程 6 阶段）
每个阶段产物都可查看、可修改后重新生成，前一阶段产物决定后一阶段输入：

| # | 阶段 | 产物 | 人工停点 |
| --- | --- | --- | --- |
| 1 | 剧本策划 | 标题、梗概、角色列表、场景列表、剧集正文 | ✅ 确认剧本后才进入下一阶段 |
| 2 | 角色/场景设计 | 角色图、场景图（多版本可选） | ✅ 可改视觉提示词后重新生成 |
| 3 | 分镜规划 | 分镜表（镜头、画面、提示词） | ✅ 可修改 |
| 4 | 参考图生成 | 每个分镜的首帧参考图 | ✅ 可修改 |
| 5 | 视频生成 | 视频片段（三种生成方式可切换） | ✅ 可修改后重新生成 |
| 6 | 后期剪辑 | 最终成片（含剪辑/配乐/字幕） | ✅ 最终交付 |

### 2.3 产物（长期保留，可导出）
- 剧本数据、角色/场景图、分镜、参考图、视频片段、最终成片
- 全部**本地留存，并支持导出**

### 2.4 三条一次性短管线（无分阶段人工停点，后台跑 + 进度订阅）

| 管线 | 输入 | 产物 |
| --- | --- | --- |
| 文艺短视频 | 灵感或完整文案 | 图文拼接或动态成片（图片 + TTS 配音） |
| 动作迁移 | 角色图 + 动作视频 | 角色完成指定动作的视频 |
| 数字人口播 | 人物图 + 口播文案 | 数字人口播视频（含 TTS 配音） |

### 2.5 术语（让你和 AI 对得上话）
| 词 | 含义 |
| --- | --- |
| 项目 | 一个创作项目（一个故事 / 一部片） |
| 会话 | 一次从创意到成片的完整创作过程，对应 6 阶段状态机 |
| 阶段 | 主流程的 6 个步骤之一 |
| 产物 | 每阶段生成的结果（剧本、角色图、分镜、视频片段、成片） |
| 任务 | 短管线的一次后台执行 |

## 3. Agent 主链路

### 3.1 主流程（6 阶段状态机）
- **分步确认**：每个阶段完成后停下，用户确认 / 修改后才进入下一阶段，不自动跳过
- **可修改**：角色、场景、分镜、参考图、视频都可修改后重新生成，不每次从头来
- **可续写**：剧本可智能续写新剧集（追加剧情、新角色、新场景，用户确认后合并）

**人机边界（哪些必须人动手）**：

| 动作 | 是否必须人确认 |
| --- | --- |
| 剧本定稿 | ✅ 硬闸门：确认后才进入下一阶段 |
| 角色/场景图选版、分镜/参考图修改、视频重生成 | 可选：不改就继续，改则只重做对应阶段 |
| 续写内容合并 / 取消 | ✅ 必须人确认（合并或丢弃二选一） |
| 删除项目 / 删除产物 | ✅ 必须人确认 |

### 3.2 三种视频生成方式（第 5 阶段可切换）
- **首帧生视频**（推荐，最稳定）：以分镜首帧图为起点 + 分镜提示词生成片段
- **首尾帧生视频**：当前片段首帧 + 下一片段尾帧，画面衔接更强
- **参考图生视频**：直接读取角色图 + 场景图，强调角色 / 场景一致性

### 3.3 短管线（一次性后台执行）
一次输入 → 后台执行 → 前端 SSE 订阅进度 → 出片，中间无需人工干预；任务失败给出可读原因并可重试。

## 4. 什么算「生成得好」

### 4.1 成功标准（先定性，数字标准等第一次真实冒烟打分后定）
1. 从一句创意能走完到完整成片，中途不卡死
2. 角色 / 场景在多个镜头间保持一致
3. 风格、画面稳定，无明显崩坏
4. 用户可确认、可修改、可继续生成，不每次从头来

### 4.2 瑕疵容忍
- 个别镜头瑕疵、字幕标点错误可接受
- 由创作者本人判断好坏

### 4.3 打分方式
- 第一次真实测试用 5～10 条真实样例让产品经理打分，据此定数字标准（**待样例打分**）

## 5. 交付阶段与优先级

### 5.1 第一刀（最小可用，必做）
6 阶段主流程：一句创意 → 完整成片，全链路跑通 + 产物留存 + 可导出（本地单机）

### 5.2 第二刀
3 条一次性短管线（文艺短视频、动作迁移、数字人口播）

### 5.3 第三刀（对外）
邀请码登录、账号隔离（用户只能看自己的数据）、多人使用

### 5.4 后续增强
剧本智能续写、跨镜头一致性 Agent、并发分镜

### 5.5 非目标（本版明确不做）
- 不做专业级剪辑工具（多轨时间线、精细调色），成片由系统自动生成
- 不做实时 / 直播类能力
- 不做会员付费、广告变现体系
- 第一刀不做登录与多人（归第三刀）

## 7. 数据与非功能要求

### 7.1 数据
- 产物（剧本、图片、视频）本地留存，可导出
- 不对外上传用户隐私（除非用户主动发布）
- **上传素材的隐私处理**：用户上传的真人照片/视频只用于本次生成，本地留存，不上传第三方、不用于训练，支持删除；生成必须发模型厂商时在前端明确告知

### 7.2 非功能
- 视频生成慢（单片段约 1～2 分钟），**必须异步 + 进度提示**，不能阻塞界面
- 文生图约 10～20 秒 / 张可接受；视频 1～2 分钟 / 片段可接受
- 文件限制：图片 jpg/png/webp ≤25MB；视频 mp4 ≤100MB
- 视频参数默认：16:9、720P、单片段 5 秒，前端可改

### 7.3 内容安全红线
- **禁止生成**：真实公众人物/真人肖像、侵权 IP、违法内容
- 拦截方式：提示词侧 + 生成结果侧双向拦截
- 对外上线前须再次确认合规
