## 必须问（本轮 3 个）

### 问题 1：公司能否办云平台企业实名认证？
- 为什么重要：你选了「对外做产品」，第三刀上线需要云平台**企业实名认证**，通常要 3～5 天。能办的话建议现在就并行去办，与开发不冲突。
- 选项：A. 能办，现在就去办 / B. 暂时不能，先本地自用，上线前再说 / C. 用个人身份上线（部分云能力受限）
- 推荐：A（现在就办，不阻塞后面的上线）
- 不选的后果：等到要上线才发现认证没办，白白等几天甚至更久

### 问题 2：内容安全红线（什么绝对不能生成）？
- 为什么重要：AI 生成视频会涉及真人肖像、版权 IP、违法内容，必须划清红线，避免对外后踩法律雷。
- 选项：A. 禁止生成真实公众人物/真人肖像、侵权 IP、违法内容（提示词 + 生成结果双向拦截）/ B. 只禁违法内容，真人肖像和 IP 由用户自己负责 / C. 不加限制
- 推荐：A（从提示词和生成结果两边拦，红线最清晰）
- 不选的后果：选 C 对外后可能踩肖像权/版权，产品有法律风险

### 问题 3：用户上传素材（真人照片/视频）怎么处理？
- 为什么重要：动作迁移、数字人口播会传真人照片/视频，属于个人信息，涉及隐私边界。
- 选项：A. 只用于本次生成，本地留存，不上传第三方、不用于训练，支持删除 / B. 可能传给模型厂商处理（生成需要）/ C. 不关心
- 推荐：A（本地留存 + 明确告知用途 + 可删除；生成必须发模型时也在前端告知）
- 不选的后果：选 B 且不告知，可能泄露用户照片给模型厂商，违反隐私承诺
