# AI造梦机 · 使用与运维说明

更新：2026-10-05。适用于本地故事短视频、漫剧视频和快捷短视频工具。最新工程结果见[项目状态](项目状态.md)。383/78为口播批次历史结果，原生声画样片的台词及精细同步仍待听审，见[原验收](evidence/口播与动作修复/验收记录.md)。下文双样片与费用记录保留历史含义；供应商实付未知，不能将估算写为对账完成。

## 1. 创作和继续已有作品

登录后，在创作台选择故事短视频或漫剧，填写创意、选择可用模型和需要的知识资料，再创建项目。故事默认一集；漫剧首期为单集视频。每个阶段生成后先检查内容，必要时编辑、选版或局部重新生成，再确认下一阶段。最终成片可以预览、下载并确认归档。

「我的作品」用于继续已有项目。仅打开页面、刷新进度、查看历史、保存编辑和确认阶段，不应自动发起收费模型生成。普通用户可选择公开模型；平台设置与系统沙盒只向管理员开放。

### 口播与角色动作短片（2026-10-05更新）

角色动作短片只需选人物图并填写动作描述，再点击生成；不再要求上传当前模型未使用的动作视频。已有任务保留原视频引用，不代表真实动作迁移已接入。

图片配音口播提供两种模式。新草稿默认「人物嘴型同步」：使用wan2.6-i2v直接生成匹配的声音和嘴型，生成10秒720p素材，再裁去持续静音尾段，成片可能短于10秒；文案最多40个非空白字符，建议单人物正面或半身图。原片保留供恢复和复查；全静音音轨报错，裁尾不证明台词或嘴型准确。音色由模型生成，暂不能指定Edge TTS声线。按项目现有价格表约¥7.232/次，裁尾不改变原生成费用，实付以供应商账单为准。另一种「静态图片配音」沿用Edge TTS加图片合成，嘴巴不会动。旧草稿与历史任务按静态模式兼容，切换到嘴型需要主动提交新的生成。

嘴型结果必须保留模型原生音轨，完成前检查视频和音轨；缺音轨或供应商失败会显示错误，不会自动用静态图或另外配音冒充成功。供应商已受理时可按原任务查询或下载续接，未知提交不能自动重提。生成后请听看核对台词是否完整、人物是否张嘴以及声音与口型是否一致；40字符限制不保证模型每次逐字读完。

### 三个容易混淆的动作

选择新视频模型：打开故事作品的“视频生成”，在“生成模型”中选Seedance 2.5或Veo 3.1，确认时长与费用后保存。已有片段不会变化；可在镜头列表只选一个镜头重新生成，检查人物、动作和段内切镜，再决定其他镜头。角色动作短片也可选择两种模型。

Seedance每段5秒，720P约¥9.40、1080P约¥21.12；Veo每段8秒，两档约¥25.60。分镜图+角色图+场景图合计上限分别为30和3；超限不自动丢图。Veo不支持1:1，首尾帧仍需已有真实尾帧。失败提示规格不兼容时应调整关联素材或选择兼容模型，重复点击不能解决。

估算并非供应商实付：Seedance按token计费，秒价为近似；4个Veo片段仅视频估算¥102.40，可能超过默认账号月预算100元。系统按调用预留，不自动提高额度。新模型尚无本项目真实质量对照，默认及旧作品不替换。完整参数见[接入合同](阶段文档/用户模型选择技术适配.md)。

| 动作 | 系统做什么 | 费用含义 |
| --- | --- | --- |
| 刷新页面 / 刷新恢复状态 | 读取已保存状态，不重新提交生成 | 不产生新的模型生成请求 |
| 继续未完成阶段 / 继续未完成任务 | 沿用原执行输入和模型，查询或下载已受理的图像/视频任务；继续未提交或明确未受理的步骤 | 成功产物复用；未提交或`rejected`步骤的新attempt仍正常预留、可能计费 |
| 重新生成 / 用这份输入继续创作后再次生成 | 以当前确认的输入发起一次新的生成执行 | 可能产生新费用；不是无条件免费重试 |

## 2. 失败或中断后怎么处理

1. 从「我的作品」打开出错项目或快捷任务，先看具体错误。若只是页面断线，后台任务可能仍在运行，等待状态更新，不立即重新生成。
2. 状态为失败或中断时，页面查询恢复记录。出现「继续未完成阶段/任务」后，可按原输入继续。执行进度仍由后台状态及 SSE 更新，离开页面不等于取消后台工作。
3. 若提示模型、设置、上游素材、知识资料版本或原任务之后的操作发生变化，原执行不能继续。先核对现在要用的版本，再决定是否重新生成；系统不会把已提交任务移植到一份不同的输入上。
4. 若提示「模型侧结果待核对」，说明提交是否被接受尚未确认，且没有足够的任务 ID 或结果信息安全续接。此时不提供继续按钮；先由管理员核对供应商侧任务和费用。反复刷新只查询状态，不能把未知结果自动变为失败或免费。
5. 明确HTTP未受理（如余额不足402）或本地预算/停止门禁记为`rejected`。问题解决且原输入未变化后，可人工继续；系统复用已成功部分，只为被拒绝位置创建新的attempt，提示需要新提交及正常预算。`unknown`以及408/409/5xx等结果不明的提交仍需核对，不能套用此规则。
6. 旧任务没有恢复快照，或已受理的供应商任务最终失败时，可能没有继续入口。界面保留原因、原输入及已有产物，可在检查后明确发起新的生成。

已有产物不会因为恢复失败被清空。继续任务必须属于本人、未被删除且没有另一执行占用；改变模型偏好用于后续生成，不改变历史结果，也不能绕过原输入校验。

恢复目前针对有记录的图像/视频供应商任务，文艺短视频已完成的短文扩写也可复用。在线Edge TTS没有供应商任务续传：快捷任务继续时可能重新合成配音；独立漫剧音频阶段没有相应模型任务记录时，使用原阶段明确重试，不宣称能够接回上一次TTS网络请求。

**当前核对边界：** 前端提供状态说明和刷新入口，尚不是供应商账单管理或人工对账操作台。未知提交不能仅凭超时、页面刷新或删除本地记录认定为未计费；有供应商证据后再由运维按真实结果处理，不能直接清空预留来制造“可用余额”。

## 3. 如何理解本月生成额度

工作区的额度行展示当前账号的数据，按北京时间自然月计账。它用于控制后续生成，并非钱包或供应商充值余额。

| 展示项 | 含义 |
| --- | --- |
| 按表估算 | 根据任务用量和本次记录的模型价格表计算的已完成调用费用；不等于供应商实付账单 |
| 已预留 | 已获准但尚未完成结算，以及提交结果未知的调用占用额度 |
| 可用额度 | 账号月限额减去按表计入金额与预留，最低显示为 0 |
| 供应商已报告费用 | 仅有明确供应商费用记录时展示；`null` 显示「待核实」，不能当作实付 0 元 |
| 运行中任务 | 当前账号处于 pending/running 的执行数及账号并发上限；平台另有总上限 |

默认平台月预算为 **500 元**，账号月预算为 **100 元**；默认平台同时最多 **2 个**执行，单账号最多 **1 个**。管理员可配置这些值。平台预算按所有账号合计判断，所以个人仍有可用额度时，也可能因平台预算不足而被阻止。

价格缺失或无效时，该模型的收费调用会被拒绝，不能按免费模型处理。额度读取失败仅影响展示，可重试读取，不阻断作品浏览、编辑保存、确认或下载。实际生成是否允许，始终由后端检查。

## 4. 管理员配置

用户端独立入口为 `http://127.0.0.1:3030/user`，只展示创作台、我的作品、短视频工具及知识库，切换页面和登录后保持用户端路径；即使当前账号具有管理权限，也不展示设置和沙盒。它沿用当前登录账号与作品，不创建访客账号、不改变后端角色权限。管理员工作区仍使用根入口 `/`，管理接口继续校验真实角色。

业务配置放在本项目 `.env`，改动后重启后端。不要把密钥、邀请码或令牌粘贴到文档、前端配置或公开截图。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `MAX_ACTIVE_EXECUTIONS` | `2` | 全平台 pending/running 执行上限 |
| `MAX_ACTIVE_EXECUTIONS_PER_USER` | `1` | 单账号 pending/running 执行上限 |
| `MONTHLY_BUDGET_CNY` | `500` | 全平台按账本控制的月生成预算 |
| `MONTHLY_USER_BUDGET_CNY` | `100` | 单账号按账本控制的月生成预算 |
| `MODEL_COST_RATES_JSON` | 未设置时读取 `backend/model-cost-rates.json` | 管理员覆盖模型估价表；每项必须包含币种、费用口径和可核对来源 |
| `ADMIN_USER_IDS` | 空 | 显式管理员账号名单，不因注册自动提权 |
| `PUBLIC_*_MODELS` | 见配置示例 | 用户公开可选模型，与协议能力共同限制范围 |

费用按模型的文本输入/输出 token、图片张数或视频秒数与分辨率计算。提交前预留，完成后按可取得的真实用量计算；没有供应商费用数据时仍是按表估算。配置价格、汇率或可选模型发生变化时，需要核对价格覆盖和来源，再验证新请求；旧账本保留当时的价格快照。

普通账号通过 `GET /api/usage` 查看本人额度；管理员另可通过 `GET /api/admin/usage` 查看平台汇总。管理接口仍需后端鉴权，不把管理员汇总直接暴露给普通账号。

## 5. 常见错误与处理

| 现象 / 错误 | 处理方式 |
| --- | --- |
| 429，并发已满 | 查看当前执行并等待结束；不要通过反复点击、另开页面或启动第二个 worker 绕过限制 |
| 402，平台或账号预算不足 | 查看预留、已估算费用和待核对项；管理员确认预算后调整，或等待下一账期 |
| `BUDGET_PRICE_UNCONFIGURED` | 管理员补齐该模型的价格来源和适用单位；用户也可主动选择已有价格且兼容的模型用于新的生成 |
| 原输入已变化 / `RESUME_INPUT_CHANGED` | 核对模型、参数、上游选版和知识版本；继续原任务被拒绝，按当前输入重新生成属于新费用动作 |
| 缺少恢复快照 / `RESUME_INPUT_MISSING` | 历史任务不伪造快照，保留现有产物；确认后发起新的生成 |
| 提交结果未知 | 核对供应商记录，保留预留；不自动重提，也不把保留的结果改写成新生成成功 |
| 查询/下载失败但已有供应商任务 | 条件仍满足时用「继续未完成」查询或下载原任务，不先点普通重新生成 |
| 额度状态暂未更新 | 点击额度行的重试；此读取异常不会代替后端的预算判断 |

## 6. 启停、数据与故障恢复

当前维持 **单后端 worker + 本地 SQLite + 本地 Qdrant + 本地媒体目录**。执行与预算相关写入使用 SQLite 事务控制，但不能由此推定多进程、分布式队列或多机部署已完成。不要直接以多个 uvicorn worker 或复制实例扩容；本地 Qdrant 的文件锁和其他任务状态也需要一并适配。

日常启动方式与依赖见 [README](../README.md)。维护重启前先检查项目执行状态，尽量等待 active 任务结束，再停止本项目的明确进程。不要使用不区分项目的进程组清理方式。启动后检查前后端健康接口，再打开作品核对状态和媒体。

本项目 `data/` 包含应用数据库、执行/供应商任务/费用记录、知识数据和媒体。备份需要保持数据库和文件一致，不能只复制成片或只复制一个 SQLite 文件；停服务后进行一致性备份，恢复后验证账号、版本、媒体、知识索引、供应商记录与费用账本。当前没有自动云备份和生产恢复时限承诺。

重启不自动重新提交付费生成。已完成且可确认的结果仍可读取；未完成执行先进入可判断的中断状态，用户查询恢复条件并显式继续。已记录的供应商任务可能在本地服务停止时继续运行，必须使用原任务记录核对，不能用本地中断推断供应商取消。

## 7. 验收与证据

恢复验收要覆盖：执行归属、已删除项目、原输入变更、重复点击/网络重传、供应商未知提交、已完成结果下载、跨进程重启及剩余步骤继续。费用验收要覆盖：全局与账号并发竞态、预算预留与释放、未知提交保留、重复调用不重复占款、价格缺失、按用量计算和供应商费用未知。

真实样片另按既有质量标准评价，记录模型、镜头、耗时、费用口径和 bad case。工程恢复通过不能替代人物一致性、在线配音与字幕观感评分。

本轮结果见[真实样片验收](evidence/真实样片验收/验收记录.md)与[样片预览](evidence/真实样片验收/样片预览.html)：两条1人1场景1集2镜头样片均完成并播放到结束。视频第1镜头保存任务ID后主动终止隔离worker，再由新进程恢复；两镜头总视频POST仅2次，未重复提交首镜头。真实HTTP402后充值恢复也复用了第一张图，仅为第二张图新建attempt。

本轮30条模型账本为28 completed、1 rejected、1 uncertain；按表估算合计9.34644元，另一次LLM超时预留0.114967元，供应商实付为null，Edge TTS不计入这30笔。故事灯塔尺度、人物合成感和漫画风格/信封颜色仍需改善，配音自然度尚未人工听审。当前3030/8030运行新版本并已验证账号100元/月、平台500元/月与并发2/1展示；历史267/60证据保持原日期，不能作为当前测试数量。
