# AI造梦机 · 模型选型

> 更新：2026-10-04  
> 决策：D4 已定 AIHubMix 网关组合

## 1. 选型原则

1. 国内可用、一套 Key 覆盖文本/图/视频  
2. 输出可结构化校验  
3. 成本可控（月 ≤ 500）  
4. 客户端可插拔，避免绑死单一厂商 SDK  

## 2. 候选路径

| 路径 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| 通义 / 万相直连 | 官方能力清晰 | 多账号多计费、集成碎 | 保留可插拔，非当前默认 |
| 火山方舟等 | 生态完整 | 迁移成本 | 备选 |
| **AIHubMix 网关** | 一 Key 多模、OpenAI 兼容 | 多一跳依赖 | **当前采用** |

## 3. 当前选型

| 能力 | 当前开放选项 / 实现 |
| --- | --- |
| 网关 | AIHubMix |
| LLM | qwen3.5-plus / qwen3.5-flash |
| 图像 | qwen-image-2.0 / qwen-image-2.0-pro |
| 首帧视频 | wan2.7-i2v / wan2.6-i2v / Seedance 2.5 / Veo 3.1 |
| 首尾帧视频 | wan2.7-i2v / Seedance 2.5 / Veo 3.1（需真实尾帧） |
| 参考图视频 | wan2.7-r2v / Seedance 2.5 / Veo 3.1 |
| 嘴型口播 | wan2.6-i2v，独立10秒原生声画模式 |
| TTS | Edge TTS（服务端调用在线语音服务，不是本地离线模型） |
| 后处理 | FFmpeg |

登录用户通过创作表单和作品工作区选择生成模型，管理员负责配置可公开的兼容白名单。`GET /api/models` 仅返回可选项，不返回网关地址、密钥或管理配置；设置与沙盒仍仅管理员可访问。

漫剧开放文本和图片；故事按视频模式展示兼容选项；文艺短视频开放短文扩写与生图模型，角色动作工具只用参考图视频模型，图片配音口播不显示无关生图 / 视频选项。详见 [用户模型选择技术适配](../阶段文档/用户模型选择技术适配.md)。

选择保存为后续生成偏好，不自动重生成、覆盖旧产物或把旧版本标成新模型。接口适配、持久化和历史模型记录已做工程验收；本轮新增候选之间的画质、耗时、成本以及新版付费完整样片尚未做真实对比。

## 4. 切换门槛

2026-10-05增量：Seedance 2.5（`doubao-seedance-2-5-260628`）作为优先试验候选，Veo 3.1（`veo-3.1-generate-preview`）作为对照；已接入不代表评优。两者均未在本项目付费出片，现有默认和旧项目选择保留。Seedance每段5秒，Veo每段8秒；Veo不支持本项目1:1作品且多图最多3张。能力与估算见[接入合同](../阶段文档/用户模型选择技术适配.md)。

以下门槛用于平台替换默认模型或宣称候选优于原模型；用户在已开放模型中手动选择不等于这些质量门槛已通过：

1. 主评测集重跑并通过 D7  
2. 客户端超时 / 重试 / 错误码适配完成  
3. 预算影响评估并经产品确认  
4. `.env.example` 与设置页文案更新  

## 5. 明确不做

- 前端直连模型（密钥泄露）  
- 未经真实评测就宣称新候选质量更好，或静默替换用户已选择的模型
