# AI造梦机 · Agent 需求文档

> 更新：2026-10-04  
> 形态：固定阶段编排（Orchestrator / ComicWorkflow / ShortPipelines）作为执行底座；可选多Agent在单阶段内规划、执行与审稿，不能越过阶段确认或费用约束，详见[多Agent协作](../多Agent协作.md)。

## 1. Agent 目标

在用户确认的节奏下，把创意稳定推进为可导出成片，并在失败、中断、改稿时保持可恢复与可解释。

服务对象是从一句想法、短文或已有角色资料开始创作的个人创作者。编排承担剧本拆解、素材传递、生成和合成，用户决定作品内容、选用模型及是否接受阶段结果。目标是减少在多个步骤间手工搬运素材与找回进度的负担；当前不宣称已验证节省多少时间或费用。

## 2. Agent 分解

| Agent / Runner | 输入 | 输出 | 是否调模型 |
| --- | --- | --- | --- |
| 剧本（故事 / 漫剧各自编排） | idea + 风格/集数等 | 结构化剧本 JSON | 是 |
| 角色/场景 | 剧本角色与场景描述 | 图片 + prompt | 是 |
| 分镜 | 剧本 + 角色信息 | shots 列表 | 是 |
| 参考图 | 分镜 + 角色/场景图 | 镜头参考图 | 是 |
| 视频 | 参考图 / 模式参数 | 片段 mp4 | 是 |
| 成片 | 视频片段 | final mp4（FFmpeg） | 否（工具） |
| 漫剧镜头对白 | 漫剧剧本 + 角色场景 | 漫画镜头、对白与时长 | 是 |
| 漫剧镜头图 | 镜头描述 + 角色参考 | 漫画镜头图片 | 是 |
| 漫剧配音 | 对白 + 声音设置 | 角色语音 | 是（在线 TTS） |
| 漫剧合成 | 镜头图 + 配音 + 字幕 | 带基础运镜和字幕的 MP4 | 否（FFmpeg） |
| 文艺短视频 Runner | 文案/灵感 | 成片 | 是 |
| 动作短片 Runner | 角色图+提示词（+可选动作视频） | 成片 | 是 |
| 口播 Runner | 人物图+文案 | 成片（TTS+合成） | 是/工具 |

故事短视频与漫剧是两条独立六阶段链路；三种快捷 Runner 只属于短视频工具。知识库由两条主链路共用，在各自剧本 / 分镜阶段检索；快捷工具暂不接 RAG。新建故事默认 1 集，漫剧当前也按单集生成，成品是 MP4。

## 3. 人机边界（强制）

| 动作 | 决策者 |
| --- | --- |
| 是否开始生成 / 重试 | 用户 |
| 是否进入下一阶段 | 用户 |
| 是否导出 | 用户（且依赖有效） |
| 模型调用、落盘、状态机 | 系统 |
| 选择本次及后续生成模型 | 用户（在平台已开放且兼容的模型中选择） |
| 网关配置、平台模型白名单与管理诊断 | 管理员 |
| 内容是否违规 | 系统拦截（可失败） |

## 4. 状态与恢复需求

1. 执行账本持久化，支持多订阅 SSE。  
2. 进程崩溃后：可确认完成的补 done；不可确认的标 interrupted。  
3. **禁止**启动时自动重新提交付费任务。
4. 项目保存 `model_selection`；任务快照及历史产物记录实际 `model_usage`。修改模型偏好只影响后续生成；生成中拒绝修改，切回旧版本必须保留旧版本的模型记录。

## 5. 工具需求

2026-10-05视频增量：模型选择扩展为Seedance2.5/Veo3.1兼容模式；阶段Agent只围绕已确认镜头工作，不擅自改人物、追加剧情或让一个片段重演全片。规格与费用由工具校验。后期实际只有格式统一与按顺序拼接，禁止宣称完成未实现的配乐/混音/调色。角色、动作与前后承接必须以实际媒体验收，不能凭路径判合格。
