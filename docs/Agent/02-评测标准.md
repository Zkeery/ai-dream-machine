# AI造梦机 · 评测标准

> 对齐决策台账 D7；更新：2026-10-11（D7 由四维改为五维加合规红线）

## 1. 视觉 / 成片标准（D7）

2026-10-11 修订：与简历和对外口径保持一致，改为「五维 + 合规红线一票否决」。镜头运动、配音字幕本来就在漫剧验收里检查。

### 1.1 五维（每项 1～3 分）

| 维度 | 3 | 2 | 1 |
| --- | --- | --- | --- |
| 需求符合 | 贴合创意和剧情要点 | 大致贴合，有偏差 | 跑题或缺核心情节 |
| 人物一致 | 角色外貌、服装、场景在多镜头间稳定 | 偶有跳变 | 反复变样 |
| 画面质量 | 清晰、构图完整、少崩坏 | 可用但有瑕疵 | 大面积崩坏、模糊或主体被裁切 |
| 镜头运动 | 动作和运镜自然连贯，幅度适中 | 偶有迟缓、滑步或跳帧 | 画面静止、严重跳帧或动作错乱 |
| 配音字幕 | 配音自然、字幕准确且与画面同步 | 可用但有错字或轻微不同步 | 缺失、错误或明显不同步 |

### 1.2 合规红线（一票否决）

无违规内容（真人肖像、侵权 IP、违法内容，对齐 D10），只判「通过 / 不通过」，不打分，不参与求平均。不通过即该条直接不合格，其他维度分数再高也不合格。

### 1.3 配音字幕的适用规则

- 样本本身没有配音和字幕时（例如 D7 这批故事短片），配音字幕记为「不适用」，不参与求平均。
- 漫剧样本和任何带配音的样本必须给配音字幕打分，不能填「不适用」。

### 1.4 单条通过线

同时满足以下条件才算通过：

1. 合规红线为「通过」；
2. 适用的维度全部填写（需求符合、人物一致、画面质量、镜头运动始终适用；配音字幕按 1.3）；
3. 适用维度的平均分 ≥ 2；
4. 没有任何 1 分项。

缺任一格时不判通过，也不补一个分数。只有一位评审的回收表不计算一致率或 Kappa。

### 1.5 与旧四维的对应关系

| 旧四维（2026-09-23 至 2026-10-10） | 新标准（2026-10-11 起） |
| --- | --- |
| 符合描述 | 需求符合 |
| 风格一致 | 人物一致 |
| 质量可用 | 拆成画面质量、镜头运动 |
| 无违规内容（原记 1 或 3 分、参与平均） | 合规红线，只判通过 / 不通过，一票否决 |
| — | 新增配音字幕（无配音字幕的样本记「不适用」） |

旧四维下打过的分（2026-09-23 产品经理打分、2026-10-10 A 评审）保留原样，作为「旧版四维标准下的历史记录」，不换算成新五维，也不补新分。旧规则为：四项都填、平均 ≥ 2、没有 1 分，无违规只接受 1 或 3。

## 4. 能力诚实标准

下列若宣传为已具备则判失败：

- 像素级动作迁移  
- 在静态口播模式宣称嘴型同步，或将嘴型模式工程成功当作台词与逐帧同步合格
- 专业多轨剪辑  

当前实现必须在界面与文档中如实标注。

2026-10-05视频质量补充：按镜头检查动作只发生在所属分镜、段内没有计划外切镜、人物面容/眼镜/服饰保持、相邻镜头动作进度承接。明显重复整段故事、身份变化或无逻辑跳跃时，不得仅凭分辨率与可播放判定合格。Seedance2.5/Veo3.1新增接入须分别验证PRD VID01–VID04工程项与VID05真实对照项；同参考图、同动作比较，5秒与8秒规格差异及费用须明示。没有新模型实际输出时保持“未实测”，不填写模型质量分数。

- 漫剧单独验收镜头图、角色语音、字幕、基础运镜及 MP4 播放下载。替身图片 / 音频跑通合成只证明工程，不算 COMIC07 真实画质与在线配音自然度通过。
- RAG 以冻结评测方案判定：独立留出集 Recall@5 = 0.80，H01/H07/H08 未通过；真实 LLM 采用资料质量 RAG08 单列。
- 模型选择工程检查页面选项、持久化、实际请求、运行中互斥与历史 `model_usage` 一致。用户选择可用模型不代表候选已通过主观效果对比。
- 普通用户可读公开模型目录；设置与沙盒必须后端鉴权，不能只隐藏导航。

批次与待验项见 [评测报告](04-评测报告.md)，不把历史冒烟结果复制成新版本质量结论。
