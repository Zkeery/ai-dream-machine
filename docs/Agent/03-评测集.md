## 5. 使用规则

2026-10-05新增回归输入：原“天台吃炸鸡”四镜头，依次为建立人物与场景、开袋、吃鸡、收束。先固定同一人物参考图和“吃鸡”单镜头，对Seedance2.5与Veo3.1分别出片；单镜头通过后再检查整段动作承接。新模型请求时长分别5秒与8秒，记录差异，不直接用总耗时或总费用作同规格排名。用户已有原片作为失败依据，不把工程替身结果记作此用例通过。

| ID | 检查重点 | 状态 |
| --- | --- | --- |
| VID01–VID04 | 新模型真实请求字段、时长预算、超限拒绝、混合格式拼接 | 工程结果见项目状态 |
| VID05-A | 同人物同动作，无身份变化及段内切镜 | Seedance/Veo均未付费生成，待验 |
| VID05-B | 开袋只发生一次，进食与收束按分镜承接 | 原片不合格；修复后新片待验 |

1. 主集变更需同步打分表。  
2. 替身 / mock 结果不得记入 D7 视觉通过。  
3. 平台替换默认模型或宣称新候选效果更好前，至少重跑 S1～S5 或等价集；用户可选模型的工程适配单独记录。
