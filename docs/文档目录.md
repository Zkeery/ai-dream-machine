## 维护规则

1. 需求变更只改 `PRD/PRD.md`，再同步本目录状态与相关专题文。  
2. 密钥、邀请码明文、AccessKey **不得**写入任何文档。  
3. 暂缓能力（如会员商业化）保留说明文件；需求变化时同步状态。RAG 已于 V1.2 纳入，不再标为不适用。
4. 真实付费生成结论更新 `Agent/04-评测报告.md` 与证据包，不在文档里用替身结果冒充视觉验收。
