# AI造梦机 · 价格与商业化说明

> 更新：2026-10-04  
> 状态：本版**不做**会员付费 / 广告变现（PRD 非目标）

## 1. 当前商业模式

| 项 | 结论 |
| --- | --- |
| 对终端用户收费 | 无 |
| 广告 | 无 |
| 使用形态 | 本地自用 / 邀请码内测 |
| 成本中心 | 模型调用费 +（未来）云资源 |

## 2. 成本边界（已定）

- 模型费用上限：**500 元 / 月**（D8）  
- 云资源：上线创建前单独报量级确认（部署摘要）  
- 产品策略：刷新 / 恢复不自动触发计费生成  

## 3. 未来可选价格骨架（未立项）

2026-10-05模型成本增量（不改变现有月预算）：Seedance2.5每段5秒，720P约¥9.40、1080P约¥21.12；Veo3.1每段8秒，两档均约¥25.60。4镜头仅视频部分约¥37.60/¥84.48或¥102.40，文字/图片另计，可能触及默认账号月预算100元；不自动提高额度。

估算使用固定8元/美元预算系数，不是实时汇率。Seedance按token计费，上述为模型页秒价近似并向上取整后的预算估计；不能当作真实支出或费用上限。调用前沿用预算预留，完成后实付仍以供应商账单为准。价格来源与取值见[模型接入合同](../阶段文档/用户模型选择技术适配.md)及`backend/model-cost-rates.json`。

仅作评审备忘，**不是当前方案**：

| 方案 | 说明 | 风险 |
| --- | --- | --- |
| 邀请码内测免费 + 成本内部承担 | 现状延伸 | 滥用调用 |
| 按次 / 按分钟成片计费 | 对齐成本 | 需计量与账单 |
| 月会员含额度 | 常见 SaaS | 需账户与支付 |

任一方案启动前需新立项、合规与支付评估。

## 4. 结论

现阶段用「成本上限 + 人工确认生成」控制商业风险；价格表待正式商业化时另建。
