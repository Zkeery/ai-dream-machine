# AI造梦机 · 数据埋点表

> 更新：2026-10-04  
> 现状：本地自用阶段**未接入**第三方分析 SDK。下表为事件字典（key → value），便于上线后一次性接入。

## 1. 通用字段

| key | 类型 | 说明 |
| --- | --- | --- |
| event | string | 事件名 |
| ts | number | 客户端或服务端时间戳 |
| user_id_hash | string | 用户 ID 哈希（不上报明文邀请码） |
| session_id / task_id | string | 可选业务实体 |
| path | string | 页面路径 / view |
| result | string | success / fail / cancel |
| error_code | string | 失败时错误码 |
| duration_ms | number | 耗时 |
| project_type | string | story / comic；快捷任务仍使用 task type 区分 |
| model_id | string | 本次实际使用或选择的公开模型 ID，不含网关地址与密钥 |

**禁止上报**：API Key、完整创意长文本、上传文件内容、Bearer Token。

## 2. 产品事件（前端）

| event | 触发 | 关键 value |
| --- | --- | --- |
| login_submit | 提交邀请码 | result |
| home_draft_save | 草稿写入 localStorage | has_idea, tool |
| story_create_click | 点击开始造梦 | style, ratio, episodes |
| comic_create_click | 点击开始漫剧创作 | style, ratio, episodes |
| story_stage_execute | 点击生成某阶段 | stage |
| story_stage_continue | 确认下一阶段 | stage |
| story_intervene | 保存/重生成/选版 | operation, target_count |
| story_export | 导出成片 | has_version_id, result |
| shortcut_submit | 提交快捷短片 | type |
| library_filter | 作品库筛选 | filter |
| asset_reuse | 复用素材 | source_type |
| settings_open / sandbox_open | 管理员打开设置/沙盒 | result |
| model_selection_save | 保存项目 / 任务模型偏好 | project_type, model_id, result |
| project_delete | 确认删除本人故事 / 漫剧 | project_type, result |
| knowledge_select | 为故事 / 漫剧选库 | project_type, library_count |

## 3. 工程事件（后端，可选）

| --- | --- | --- |

## 4. 落地建议

2026-10-05视频扩展：片段增加`requested_duration_seconds`；费用账本的`units.seconds/resolution`为计价请求规格，均不等于实际成片时长。按`model_usage`分析新模型，不以当前选择回填旧产物。真实输出、人工评分、供应商实付与估算分列；本轮不新增第三方埋点或声称已采集这些业务指标。

1. 本地期：用服务端日志与 SQLite 统计即可（见上线后分析报告）。
