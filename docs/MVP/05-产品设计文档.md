# AI造梦机 · 产品设计文档（0→1）

> 更新：2026-10-04  
> 视觉基线：夜幕影院 3D（用户确认 V05）  
> 详细视觉说明见 `阶段文档/夜幕影院3D-*`

## 1. 设计目标

创作界面服务三类具体任务：从一句想法开始、逐阶段检查和改稿、离开后找回作品继续。首页先让用户选故事短视频或漫剧，进入作品后才展示该链路的步骤；次要配置不能遮住输入与下一步动作。

1. 第一屏建立「造梦 / 电影感」品牌，而不是后台仪表盘。  
2. 创作主路径短：创意 → 开始造梦 → 阶段工作区。  
3. 故事短视频与漫剧是两条并列主路径，快捷工具归入短视频，结果统一进作品库。

## 2. 信息架构

```
登录
 └─ 创作台（首页）
     ├─ 故事短视频（默认 1 集）
     ├─ 漫剧创作（单集 MP4）
     └─ 创作设置 / 资料选择 / 生成模型选择
 └─ 故事工作区 / 漫剧工作区（各自六阶段）
 └─ 短视频工具（文艺短视频 / 角色动作 / 图片配音）
 └─ 我的作品（故事 / 漫剧 / 快捷；故事与漫剧可删除）
 └─ 知识库（两条主链路共用）
 └─ 设置 · 沙盒（仅管理员）
```

## 3. 关键页面职责

模型选择增量（2026-10-05）：沿用现有选择器，不新增创作流程。Seedance2.5与Veo3.1显示易读名称、每段5/8秒、规格限制和按720P/1080P估算的片段费用。与当前比例不兼容时显示具体原因并禁用生成；选择本身只保存偏好。已有素材继续显示历史实际模型，避免用户误以为切换后旧片已经更新。

| 页面 | 用户任务 | 成功态 |
| --- | --- | --- |
| 登录 | 输入邀请码 | 进入创作台 |
| 创作台 | 写创意并选择方式 | 进入工作区或提交快捷任务 |
| 故事工作区 | 逐阶段生成 / 确认 / 编辑 | 可导出或继续 |
| 漫剧工作区 | 剧本→角色场景→镜头对白→漫画镜头→配音→成片 | 带基础运镜和字幕的 MP4 可播放下载 |
| 短视频工具 | 一次出片 | 任务进度可恢复 |
| 我的作品 | 找回或删除本人项目 | 正确打开来源；删除确认与执行中保护 |
| 知识库 | 管理创作资料、检查检索来源 | 故事 / 漫剧可按项目选库 |
| 模型选择 | 选择本次及后续使用的兼容模型 | 普通用户可用，保存并显示实际选择 |
| 设置 / 沙盒 | 管理员查看配置与诊断 | 只读，无密钥；普通用户访问被拒绝 |

## 4. 交互原则

1. 高风险生成必须用户点击触发。  
2. 失败保留输入；中断给出可读原因。  
3. 「待更新」比静默覆盖旧结果更安全。  
4. 能力做不到的（嘴型、像素动作）界面如实说明。  
5. 四档宽度（390 / 768 / 1280 / 1440）无横向溢出。
6. 模型偏好改变不自动重生成；选回历史版本仍显示该版本真实模型。无法加载可用模型时明确提示重试。

## 5. 视觉语言（摘要）

- 夜幕影院：WebGL 门框 / 光点 / 视差；可暂停动态；WebGL 不可用降级静帧。  
- 品牌信号：AI造梦机 / DREAM MACHINE 处于第一屏强位置。  
- 避免把首页做成多卡片运营仪表盘。
- 四个主导航鼠标悬停时放大并高亮，键盘焦点可见，减少动态模式不放大，移动端保留易点击区域。
- 首屏右侧使用不同的人物与场景图：左雨夜女孩，右云上城市；下方电影灵感参考保留官方图及来源链接。该参考区不作为平台生成效果证明，也不表示已完成商业发布授权核验。
- 首屏移除“单集漫剧……”技术说明，保留创作参数与必要能力提示；新建故事默认 1 集。

## 6. 与实现的关系

设计变更若影响 API 或状态机，必须同步 PRD 与技术接入方案，不得只改前端文案。
