# AI造梦机 · 立项报告

> 更新：2026-10-04  
> 决策依据：当前 PRD V1.3、决策台账与阶段闸门记录；历史真实验收不随版本升级自动延伸。

## 1. 项目名称与定位

- 名称：AI造梦机  
- 一句话：AI造梦机是一款面向个人创作者和小型内容团队的 AI 视频创作平台，帮助用户将创意或故事，通过可编辑、可确认的制作流程，转化为故事短视频或漫剧视频。
- 端口：后端 8030 / 前端 3030（项目独立）

## 2. 立项理由

项目面向有故事想法、但难以独立完成剧本拆解、画面生成、配音和合成的个人内容创作者。要解决的具体问题是创意难以变成可观看的一集，以及改稿、续作时输入、素材和版本分散、进度难以找回。

故事短视频适合需要连续视频镜头的故事表达；漫剧适合以漫画画面、角色对白、字幕和基础运镜完成一集。两条链路允许用户逐阶段确认和改稿，共用自己的角色资料、世界观资料及作品管理。快速文艺短片、角色动作片、图片配音则保留为短视频工具。

这些是当前产品需求与待验证的用户问题，尚没有外部用户访谈或量化收益证明。先用本地 MVP 验证能否完整出片、是否好改和好找回，再决定上云。

## 3. 目标与非目标

**目标（MVP 已覆盖主链路）**

- 六阶段故事成片  
- 六阶段漫剧视频（镜头图、角色配音、基础运镜、字幕 MP4）
- 三条快捷短视频工具
- 邀请码登录与账号隔离  
- 统一作品库、草稿恢复、版本依赖与项目删除
- 两条主链路共用创作知识库；用户可选兼容生成模型；设置 / 沙盒仅管理员访问

**非目标（本版）**

- 专业多轨剪辑、直播、会员广告、团队协作权限体系。RAG 已于 2026-10-04 纳入 V1.2 创作知识库范围，详见 PRD 第 10 节。
