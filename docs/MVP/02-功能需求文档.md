# AI造梦机 · 功能需求文档（MVP 摘要）

> 权威需求正文：[PRD V1.3](../PRD/PRD.md)；本表同步故事 / 漫剧双链路、共用知识库、权限与用户模型选择。
> 本文是评审用功能清单摘要（1→N 功能条目索引），细节以 PRD 为准。

## 1. 用户与价值

- 用户：短视频 / 短剧 / 漫剧创作者、自媒体；次要小团队
- 价值：帮助个人创作者和小型内容团队，将创意或故事通过可编辑、可确认的流程转化为故事短视频或漫剧视频。

核心问题是从想法到成片步骤多，剧本、角色素材、生成参数与版本容易散落；生成失败或隔天续作时，还需要找回输入和进度。以下场景是产品需求定义，不是已经验证的市场调查结论。

| 使用场景 | 用户要完成的任务 | 产品应提供的结果 |
| --- | --- | --- |
| 有一句故事创意 | 做一集有连续视频镜头的故事短片 | 默认 1 集，逐阶段确认后导出 MP4 |
| 有漫画故事或角色对白 | 做一集漫画画面驱动的漫剧 | 独立漫剧链路，镜头图、配音、字幕与基础运镜成片 |
| 只有短文或一张人物图 | 快速做一条短视频 | 按输入使用三种快捷工具，不创建漫剧阶段 |
| 需要续作或改稿 | 保留角色 / 世界设定，找回作品并局部修改 | 共用本人知识库，保留草稿、版本与依赖关系 |
| 想尝试不同生成效果 | 主动选择可用模型并追溯结果 | 选择可见、可保存，历史作品记录实际模型 |

## 3. 关键业务规则

1. 只有用户明确提交才调用付费模型。  
2. 刷新、断 SSE、服务重启不得自动重交模型。  
3. 默认导出要求依赖有效；历史成片可按版本下载。  
4. 账号只能访问自己的会话、任务、媒体与素材。
5. 故事与漫剧分成两条主链路；三种快捷工具仅服务短视频，不套入漫剧阶段。
6. 普通用户可选平台公开的兼容生成模型；网关和管理配置仍仅管理员可见。没有可用选项时明确报错，不静默换模型。
7. 修改模型偏好不覆盖历史产物；生成中的项目不可修改，历史版本保留实际模型记录。
