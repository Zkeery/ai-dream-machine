# AI造梦机 · 竞品深度研究报告

> 类型：idea 阶段 · 深度竞品（1 份）  
> 更新：2026-10-04  
> 研究对象：小云雀等故事创作工具及综合工作流产品的能力比较。
> 范围：保留早期竞品研究记录及其当时的能力比较；本文不定义当前产品需求。当前目标用户、问题、场景和验收以 [PRD](../PRD/PRD.md) 为准，不能因竞品具备某项功能就视为用户需要它。

## 1. 研究问题

比较「一句创意 → 成片」产品如何组织制作步骤、编辑确认与产物管理，记录可供验证的设计假设；产品是否采用仍由自身用户任务决定。

## 2. 对标能力画像（综合）

| 能力块 | 对标常见做法 | AI造梦机选择 |
| --- | --- | --- |
| 故事拆解 | 多阶段（剧本 / 角色 / 分镜 / 视频） | 采用 6 阶段，关键节点人工确认 |
| 快捷工具 | 一键短视频 / 口播 | 保留 3 条短管线，进统一作品库 |
| 素材管理 | 弱或分散 | V1.1 强化统一作品库 + 本人素材复用 |
| 一致性 | 角色参考图 | 要求图片真实进入下游调用（AC07 效果待验） |
| 商业化 | 会员 / 积分 | **本版不做** |
| 部署 | 云 SaaS | 先本地，上云暂缓 |

## 3. 差异化主张

1. **可控工作流**：每阶段可确认、可编辑、可版本依赖，而不是黑盒一键出片。  
2. **统一归档**：故事与快捷任务同一作品视图，草稿 / 任务可恢复。  
3. **诚实边界**：动作迁移非像素级、口播无嘴型、中断不自动重交费——写进产品说明。  
4. **本地可自用**：无云也能跑通全链路，适合小团队内测。

## 4. 威胁与机会

| 类型 | 内容 | 应对 |
| --- | --- | --- |
| 威胁 | 大厂一键成片体验更强 | 深耕「可编辑依赖」与作品管理 |
| 威胁 | 模型单价下降导致工具同质 | 强化编排与资产沉淀 |
| 机会 | 创作者要「改得动」 | 版本 / stale / 局部重生成 |
| 机会 | 多账号隔离刚需 | 邀请码隔离已具备 |

## 5. 结论

历史研究形成了工作流型创作系统的方向假设。该假设需要通过用户能否完成作品、改稿和续作来验证，不作为用户需求或收益已经得到证明的结论。
