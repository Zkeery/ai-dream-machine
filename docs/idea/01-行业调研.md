# AI造梦机 · 行业调研

> 类型：idea 阶段 · 行业研究  
> 更新：2026-10-04  
> 方法：公开产品信息与项目方需求讨论的整理；未提供独立市场样本或量化行业数据，以下趋势判断不作为已证实的用户需求。

## 1. 行业定义

AI 生成视频（AIGC Video）正从「单镜头玩具」走向「可交付短片工作流」：

- 上游：大模型（文本 / 图像 / 视频）与算力网关  
- 中游：创作工具（提示词、分镜、角色一致性、剪辑合成）  
- 下游：短视频 / 短剧分发平台与广告内容生产

本产品处于**中游创作工具**：强调「从想法到成片」的完整链路，而不是单点模型体验。

## 2. 市场驱动

| 驱动 | 含义 | 对本产品影响 |
| --- | --- | --- |
| 短视频内容消耗量持续高 | 创作者需要更高产 | 快捷短片三条管线 |
| 专业剪辑门槛高 | 个人创作者不会多轨 | 自动成片，不做专业 NLE |
| 模型能力快速迭代 | 画质与可控性上升 | 网关可插拔；效果需样例验收 |
| 合规压力上升 | 肖像权 / IP / 违法内容 | 红线双向拦截是上线前置 |

## 3. 产业链角色与我们的位置

```
创意输入 → [AI造梦机：编排+人机确认+产物管理] → 成片导出 → 分发平台
                 ↑
           模型网关 / TTS / FFmpeg
```

不争夺：分发平台、广告交易、专业剪辑软件。

## 4. 关键趋势与风险

| 趋势 / 风险 | 判断 | 应对 |
| --- | --- | --- |
| 角色一致性仍是痛点 | 高 | V1.1 强调参考图进入下游；AC07 真实效果待验 |
| 视频单价高、耗时长 | 高 | 月预算 500；用户明确触发；不自动重跑 |
| 工具同质化 | 中 | 差异化在「六阶段可控工作流 + 统一作品库」 |
| 合规与实名 | 高（对外时） | 当前本地自用；上线前专项 |

## 5. 产品假设（待用户验证）

1. 待验证的问题：有故事想法的创作者，是否因剧本、画面、配音和合成步骤分散而难以完成一集。
2. 待验证的价值：独立的故事 / 漫剧流程、阶段改稿与统一作品管理，是否能帮助用户完成作品并继续创作。
3. 先以本地 MVP 验证流程和真实效果，再决定上云与商业化。当前需求以 [PRD](../PRD/PRD.md) 的目标用户、任务与场景为准，不以竞品能力清单直接推导。
