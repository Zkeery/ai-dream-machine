# 横向测评研究报告 · Runway / Pika

> 类型：idea 阶段 · 横向测评（N 份之一）  
> 更新：2026-10-04  
> 方法：桌面研究（公开产品能力与定位），**未做付费实测账号对比**

## 1. 测评目的

对比国际通用「AI 视频生成工具」与 AI造梦机在任务形态上的差异，避免错误对标。

## 2. 对比维度

| 维度 | Runway 类 | Pika 类 | AI造梦机 |
| --- | --- | --- | --- |
| 主任务 | 镜头级生成 / 特效 / 编辑辅助 | 短视频创意生成 | 故事级六阶段 + 快捷短片 |
| 剧本与分镜 | 弱 / 外部完成 | 弱 | 内建阶段 |
| 角色一致性工具 | 有参考图能力，工具分散 | 有限 | 设计为工作流内依赖 |
| 成片剪辑 | 偏专业或半专业 | 轻 | 自动拼接成片（非多轨） |
| 部署 | 云 SaaS | 云 SaaS | 本地优先 |
| 账号与素材库 | 成熟云账户 | 成熟云账户 | 邀请码 + 本地 SQLite |

## 3. 启发

1. 单镜头画质不是我们第一 KPI；**链路可控与可恢复**才是。  
2. 国际工具强在模型与特效；我们应用「中文创作者故事工作流」切入。  
3. 若未来上云，可学习其资产库与版本管理体验，而不是复制特效矩阵。
