# AI造梦机 · 用户调研报告

> 类型：idea 阶段 · 用户调研  
> 更新：2026-10-04  
> 方法说明：本轮以**项目方需求讨论**与决策台账为主，尚无外部真实用户访谈、问卷或可用性实验样本。本文记录产品定义与待验证假设，不视为市场研究结论。

## 1. 调研目标

1. 谁会用、为什么用  
2. 核心任务与成功标准  
3. 不能碰的红线与隐私边界  
4. 使用形态（本地 / 对外）与预算

## 2. 用户画像

| 分层 | 描述 | 优先级 |
| --- | --- | --- |
| 主要 | 短视频 / 短剧 / 漫剧创作者、个人自媒体；希望将创意完成为可观看作品 | P0 |
| 次要 | 小团队内容工作室（需要账号隔离） | P1 |
| 非目标（本版） | 专业影视后期、直播运营、广告投放团队 | — |

## 3. 项目方需求摘要（非逐字访谈记录）

| 主题 | 需求摘要 | 决策依据 |
| --- | --- | --- |
| 核心任务 | 从一句创意到完整成片 | D1 |
| 成品形态 | 要成片，不是只停在分镜 | D3 |
| 主线范围 | 故事短视频 / 漫剧各自六阶段，另有三条短视频工具，统一作品库 | 当前 PRD |
| 创作资料 | 两条主链路共用本人知识库，保留来源与版本 | PRD 第 10、12 节 |
| 模型选择 | 用户可在兼容选项中选择生成模型，设置 / 沙盒仅管理员 | PRD 第 12 节 |
| 隐私 | 上传素材仅本次生成、可删、要告知 | D5 |
| 登录 | 邀请码；企业认证暂缓，先本地自用 | D9 |
| 预算 | 模型费用 ≤ 500 元 / 月 | D8 |
| 红线 | 禁真人肖像 / 侵权 IP / 违法内容 | D10 |
| 质量 | 四维打分平均 ≥ 2 且无 1 分 | D7 |

需求确认与历史决策见 [PRD补全清单](../PRD/PRD补全清单.md) 与 [项目状态 · 决策台账](../项目状态.md)。这些文件不是外部用户访谈原始记录。

## 4. 场景地图

| 场景 | 触发 | 期望结果 | 失败不可接受点 |
| --- | --- | --- | --- |
| 故事创作 | 有梗概 / 一句话 | 六阶段后可导出成片 | 断点丢进度、悄悄重新扣费 |
| 漫剧创作 | 有漫画故事 / 角色对白 | 漫画镜头、配音与字幕形成一集 MP4 | 被混进短视频阶段、只能出散图不能成片 |
| 快捷出片 | 只要一条短视频 | 一次提交后台完成 | 失败后输入全丢 |
| 续作 | 隔天回来继续 | 作品库 / URL 恢复 | 找不回项目 |
| 素材复用 | 已有角色图 | 不下载再上传即可用 | 看到别人素材 |

## 5. 问卷建议（未执行，供后续）

建议题项：创作频率、是否会剪辑、可接受等待时长、月预算、最常做内容类型、是否上传真人照片。样本量建议 ≥ 30。

## 6. 调研缺口与风险

| 缺口 | 影响 | 缓解 |
| --- | --- | --- |
| 无外部真实用户样本 | 画像偏产品经理视角 | 本地自用验证后再扩样 |
| 未做可用性实验室测试 | 交互细节可能偏差 | 产品 / 设计走查清单 |

## 7. 结论

当前已形成目标用户、任务与场景的产品定义，可用于本地 MVP 验证；问题是否普遍存在、使用意愿以及节省时间 / 成本仍待外部用户研究。不能将项目方需求讨论称为已验证的用户收益。
