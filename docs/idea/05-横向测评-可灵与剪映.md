# 横向测评研究报告 · 可灵 / 剪映

> 类型：idea 阶段 · 横向测评（N 份之二）  
> 更新：2026-10-04  
> 方法：桌面研究；面向中文创作者生态

## 1. 测评目的

对标国内「能出片」的两条路径：AI 视频生成（可灵类）与剪辑生态（剪映类）。

## 2. 对比

| 维度 | 可灵类 AI 视频 | 剪映类剪辑 | AI造梦机 |
| --- | --- | --- | --- |
| 入口 | 提示词 / 参考图生视频 | 素材时间线 | 创意句 + 阶段确认 |
| 用户技能假设 | 会写提示词 | 会剪辑或模板 | 不会专业剪辑 |
| 故事结构 | 用户自理 | 用户自理 | 系统生成剧本 / 分镜 |
| 成片完整度 | 片段强、整片弱 | 整片强、AI 弱 | 自动合成短片级成片 |
| 生态 | 模型平台 | 抖音生态导出 | 独立本地工具 |

## 3. 结论

- 与可灵：**不拼单片段画质**，拼「多阶段项目能否管住依赖」。  
- 与剪映：**不拼时间线**，拼「从无素材到有成片」的冷启动。  
- 组合定位：AI造梦机是「生成式前期 + 轻后期」，不是替代剪映的专业剪辑。

## 4. 产品启示

保留三条快捷短片服务「剪映用户的灵感草稿」；六阶段服务「短剧结构用户」。
