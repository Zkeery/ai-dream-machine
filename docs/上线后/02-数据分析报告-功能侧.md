## 4. 功能侧建议

1. 优先补 AC07 / COMIC07 真实样片、RAG08 真实采用资料效果及独立检索失败。
2. 接入埋点后分别观察故事与漫剧各阶段转化与耗时，不把两条链路混为同一漏斗。
3. 快捷短片单独看成功率，避免被故事长链路平均值掩盖。
