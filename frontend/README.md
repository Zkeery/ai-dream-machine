# AI造梦机 · 前端

面向个人创作者和小型内容团队的AI视频创作平台正式前端：帮助用户将创意或故事，通过可编辑、可确认的流程，转化为故事短视频或漫剧视频。Next.js（App Router）+ React 19 + TypeScript strict + Tailwind CSS 4，开发端口 **3030**。2026-10-03接入「夜幕影院3D」视觉，并按PRD V1.1补齐创作闭环，使用现有依赖与原生WebGL。开发及测试使用Node.js 24。

2026-10-04当前为V1.3双主链路，已有知识库、删除、管理员权限与用户模型选择。首页右侧为雨夜女孩与云上城市两张不同图片，下方电影参考及来源保留，表单下方技术说明移除；故事默认1集，漫剧固定单集。下文31项及2026-10-03数字是对应阶段历史，当前模型选择工程回归为54项；真实模型完整样片仍待验。

- **登录页** `/login`：邀请码登录
- **工作台** `/`：顶部导航（创作台 / 我的作品 / 短视频工具 / 知识库）；设置与沙盒仅管理员可见，保留退出入口

  - **创作流程** `/?session=...`：6 阶段工作区，保存剧本/分镜编辑、选择角色/场景/阶段版本，显示下游待更新状态，逐阶段确认/重做；有效成片与历史版本分别下载
  - **我的作品** `/?view=projects`：同一列表汇总本人故事与三类快捷任务，含来源、状态、筛选、加载、错误重试与空状态；点击回到对应故事或工具任务
  - **短视频工具** `/?view=pipelines&tool=literary|motion|talking`：首页带入创意和支持的参数，草稿按工具保存；提交后后台生成，以 `&task=...` 定位具体任务，轮询恢复实际进度与结果；可主动复用本人生成图片
  - **模型选择**：创建表单展开「模型」；已有项目按当前阶段选择，保存后用于下一次生成。普通用户读取 `GET /api/models`，不读取管理配置。历史版本与单项素材显示实际模型，旧数据无记录时明确说明。
  - **设置**：管理员只读展示当前模型配置与内容安全开关（后端 `GET /api/settings`）
  - **沙盒**：管理员保护的检查入口及当前账号会话/任务统计（`GET /api/admin/sandbox`）

## 启动

```bash
cd frontend
npm install        # 首次
npm run dev        # 打开 http://127.0.0.1:3030
```

需后端已运行在 8030；登录、会话/任务/产物媒体、素材、知识库、设置和 SSE 默认通过同源 `/api` 及 Next `rewrites` 代理到后端（见 `next.config.ts`）。2026-10-04 为临时公网访问移除了客户端的 localhost 默认值；`NEXT_PUBLIC_API_URL` 仅在需要显式指定其他后端时设置。执行独立于连接，页面恢复使用持久状态轮询。

临时公网预览使用生产构建：`npm run build` 后执行 `node scripts/serve-standalone.mjs`，仍占用 3030（先停同端口 dev）。该脚本补齐 standalone 所需静态文件，并仅监听本机，由隧道公开 HTTPS。长期部署与临时隧道不是同一运行方式，当前临时地址见主项目 `docs/项目状态.md`。

## 使用与恢复

1. 在创作台填入文字与设置，切到设置或作品库再回来，或刷新页面，草稿仍保留；不同账号使用不同草稿键。
2. 首页切换快捷工具时只传递该工具支持的字段。文艺短视频继承文字和风格；故事剧集数/画幅不作为快捷工具的有效设置。
3. 提交失败保留文案、参数和已上传文件引用。未成功上传的文件明确提示重新选择。
4. 任务生成中切页或刷新，从作品库或原任务 URL 返回可恢复进度。任务状态以保存结果为准，页面重新挂载不自动开始生成。
5. 作品完成或失败后可「用这份输入继续创作」；已解析的媒体路径恢复为受所有权校验的上传文件名，新提交形成新执行。
6. 剧本/分镜编辑的「保存」只写内容与版本；「重新生成」才调用模型。角色或场景选版后受影响的阶段标为待更新，按提示更新后继续。
7. 默认成片导出拦截过期依赖；「下载历史成片」按明确版本下载。选择依赖过期的旧版不会自动把它当成有效的新产物。
8. 模型选择保存到项目与工具草稿；切换只影响后续生成，生成中不能修改。目录加载失败、模型下线或保存失败时会提示并阻止对应生成，不会静默换模型。漫剧显示文字/图片，故事视频按模式匹配；口播配音与本地合成不展示未使用的生成模型。

`view`、`session`、`tool`、`task` 保存页面上下文，刷新与浏览器导航按 URL 恢复。切到工具地址不会保留旧故事标识；访问不存在或无权访问的对象显示可读错误。

## 已知边界

- 鉴权用 `Authorization: Bearer` + `localStorage`（SSE 需自定义头），生产上线前迁 HttpOnly Cookie。
- 产物图片/视频用 blob ObjectURL 加载，不走 next/image 优化。
- 真实生成速度受模型商延迟影响（视频片段约 1~2 分钟/段），前端以「流程可用」为准。
- 3D 不包含完整可漫游地形或生成视频；减少动态、页面隐藏、场景离屏时停止动画，图形上下文不可用时保留静帧和可操作表单。
- 本次浏览器检查覆盖首页、三个工具、设置与沙盒的 390 / 768 / 1280 / 1440 宽度；详见 `../docs/evidence/夜幕影院3D/验收记录.md`。
